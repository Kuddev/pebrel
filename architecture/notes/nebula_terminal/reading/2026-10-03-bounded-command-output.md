# 有界的命令输出范围与只读文本查询

## Status

已实现。迁入当前主线后的23项读取测试通过；初次实现的完整核心回归和手动成本样本列于下方。GPUI接线单独验收，不由本记录宣称完成。

## Context

用户需要一键复制某次shell执行结果、限定该次搜索与定位，但不希望接管Agent TUI输入或先替换历史存储。已有OSC 133标记只维护提示符状态；裸绝对行号不足以证明一次执行输出在重排或后续覆盖后仍有效。

直接复制全部scrollback再截取，会增加持锁时间和大输出的常驻副本；按当前标题/提示符猜边界可能混入另一条命令。已完成输出仍在live grid内时，还可能被随后启动的程序覆写。

## Evidence

- `nebula_terminal/src/event_loop.rs::StreamProcessor::feed` 已按parser slice处理OSC；新增记录沿用同一wire order，不另解析UI标题。
- `term/reading.rs` 提供epoch+半开范围、分块读取、源列映射及完成命令查询。
- `term/reading/guard.rs` 比较D时live尾的精确字符、宽字符/换行flags及组合字符，不保存搜索映射或超链接对象。
- `term/reading/tests.rs` 覆盖所有标记切块位置、CJK/组合字符、软折行、覆盖后滚入历史、重排/清历史/切屏、十万行及极宽行。
- 初始4096-cell尾快照使200×50普通窗口的长输出无法登记；回归测试证实后，尾部守卫与单块读取预算被分开。

## Decision

1. 只记录完整、已提交的主屏A/B/C/D序列。缺失/乱序/重复或同步输出尚未提交时保守拒绝，不改变原有终端事件payload。
2. 查询地址使用会话内epoch和绝对行列；resize/reflow、reset、清历史、切屏和外部`grid_mut()`作废地址，普通追加不作废。暂不引入稳定LineId或存储迁移。
3. 每次只读最多4096个物理cell、32KiB文本/换行数据；组合序列无法完整放入预算时显式报错，不循环重试同一游标。
4. 完成命令至多32条，metadata总预算1MiB；尾部守卫独立至多32768 cells/128KiB payload，且计入同一总预算。
5. 每块只校验与其相交的尾部；复制开始和最终发布前完整校验命令范围。守卫保留D时原值，即使尾部后来进入history也不能丢弃校验。
6. 字节到源列映射和源文本只在有界返回值内存在。匹配、拼接、硬行尾空白处理以及UI回传在终端锁外进行。
7. 命令标签是有界B→C显示文本，不是shell AST，不用于自动重新执行。输出是当前保留的终端文本，不声称原始stdout/stderr分流。
8. 普通只读搜索可读取当前alt grid；命令范围操作拒绝alt，不把Agent内部对话伪装成多次shell执行。

## Rejected alternatives

- 以标题/关键字猜执行归属：没有准确边界证据。
- 仅核宽度和起止行号：live内容可在同位置覆写。
- 只做最终尾检查：中间块可能读到暂时被覆写的内容；相交块也必须验证。
- 保存整条命令输出或全量Term快照：内存与持锁成本随全部输出增长。
- 每次查询重建全部尾部ReadingCell映射：不必要的分配和重复扫描。
- 为支持复制先换全部历史存储：成本和兼容范围超过当前需求；epoch失效是明确的第一版限制。

## Consequences

默认终端状态增加少量字段，具备完整shell标记时产生有界命令metadata；并非完全零成本。读取本身不改selection、cursor、mode或PTY字节流。重排、淘汰和覆盖可能使旧结果不可用，调用方必须说明原因，不能静默复制另一段。

典型大窗口可登记长输出；真正超过守卫预算的live尾仍拒绝登记。UI要区分“无可确认范围”与“用户没有执行过命令”。

## Validation

初次实现的GNU Rust1.97.1本地隔离构建：

- `cargo test --offline --locked -p nebula_terminal --lib`：300通过、0失败、2手动样本忽略。
- `... term::reading::tests -- --ignored --nocapture --test-threads=1`：2通过。
- 本机dev样本，256-cell读取2000次：100行历史16.04ms、10万行历史12.71ms、10万列长行9.26ms。
- 32768-cell守卫捕获328.7µs；完整检查1000次290.17ms，观测最大1.01ms。
- 200列×10万行样本输出1.4MB，4883次查询，总483.40ms，单次查询观测最大771.1µs，长期metadata39401B。

迁入当前主线后，`cargo test --offline --locked -p nebula_terminal term::reading::` 的23项读取测试通过，两个手动成本样本保持默认忽略。完整原生回归由对应提交的CI执行。

以上是本机函数级样本，不是输入延迟、GPU帧率或跨机器保证。GUI输入隔离、剪贴板及焦点测试由对应UI改动承担。

## Supersedes

None。旧显示结构研究不是已实施的存储合同，本改动不将其全量换底作为前置条件。

## Revisit when

需要跨resize长期保存执行范围，或实测显示元数据/守卫成本成为瓶颈时，再评审稳定内容身份与增量变更跟踪；不得仅扩大预算来掩盖错误归属。
