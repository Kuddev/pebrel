# 本机有界命令输出恢复

## Status

已实现并完成本机 Windows CMD 验证，已提交至贡献分支供上游审核。
对应 Issue #160；此记录不表示已合入上游或正式发布。

## Context

布局和 AI 原生身份恢复不包含终端显示内容。全局补全历史没有 pane 身份，
不能通过目录猜测旧输出归属。恢复内容必须是静态显示，不能重新执行历史命令。

## Evidence

- `nebula_app/src/recent_output.rs`：命令记录、五条上限及输出尾部截取。
- `nebula_app/src/recent_output/storage.rs` 与 `storage/lifecycle.rs`：容量、原子交接和清除。
- `nebula_terminal/src/grid/snapshot.rs`：安全显示快照及 Unicode/重排测试。
- `nebula_app/src/session/local_output.rs`：本机输出引用与会话导出边界。
- `nebula_app/src/gpui_shell/workspace/windowing/output_persistence.rs`：异步保存生命周期。

## Decision

terminal 层只导出、导入静态显示数据，去除链接动作，不回放 VT；app 层复用
已确认的 shell 命令提交，每 pane 最多五条，每条编码不超过 256 KiB，保留命令
与输出尾部。独立本机 sidecar 使用版本化格式和精确记录引用，不按 cwd 匹配。

正常快照总编码不超过 16 MiB，原子交接期间允许新旧两代临时合计最多 32 MiB，
各代仍单独限额。sidecar 写入成功后才发布会话引用，成功后回收旧代；崩溃重试
保留已发布会话的有效引用，不累积第三代。总量超限先淘汰最旧记录再生成引用。

读取前检查大小，读取时限流，解码后校验。损坏输出降级且不阻断有效新保存；
真实 I/O 失败保留失败和重试语义。保存与清除串行提交，代次失效阻止旧快照
在清除后写回。关闭保存使在途旧快照失效；关闭 pane 的成功保存移除对应引用。

会话恢复开启时默认有界保存，提供关闭与清除入口；独立会话导出不携带本机
输出引用或正文。旧会话无引用时沿用原恢复行为。文档在等待保存期间被编辑时，
关窗路径重新检查脏状态，包括 Runtime 关窗，不能因之前确认而丢弃新编辑。

## Rejected alternatives

- 保存、重放原始 VT：会重放控制动作，不是安全静态恢复。
- 按目录分配全局历史：多个 pane 可有相同目录，无法证明归属。
- 把全部输出嵌入可导出的 session：扩大隐私暴露和载入成本。
- 不允许两代临时空间：有效旧快照会阻断正常原子替换。
- 为恢复引入常驻线程或新依赖：现有异步执行和原子写机制足够。

## Consequences

不恢复活进程，不重新执行命令，不恢复完整 AI 对话或 CMD 原生命令历史。
不采集不可见密码输入、TUI 内部按键或 AI 会话文件，但无法自动识别所有已经
显示在屏幕上的秘密。备用屏内容不作为普通历史导入。

活跃 AI 恢复时，静态旧输出和 AI 自身重绘可能同时留在终端历史中。
禁用本功能可回退至原布局和 AI 恢复，不以回退脚本删除用户数据。

## Validation

合并上游基线 `07afade392919c49b846c3e59556b43aef79be35` 后，另加入独立的
CLI 补全修复 `f66ae68` 做组合应用回归：1948 通过、0 失败、15 忽略。
本功能分支不包含该补全修复；此结果不表示未修复基线补全问题的独立分支全绿。
terminal 包复测 284 个单元测试、48 个集成测试及 1 个文档测试通过。
合并后 GPUI 构建、同一上游基线的架构检查和格式检查通过，没有扩大预算。
i18n 合同此前为 20 通过、1 忽略，未将其计作合并后的重新执行结果。

实际 GPUI 构建验证 CMD 保存、关窗、重复重启、最近五条、多 pane 不串档、
恢复期变窄、备用屏排除和活跃 Pi 原生会话身份保持。Pi 使用本机合成服务，
不是云端兼容性证明。两 pane 大输出测试恢复各自尾部；本机计时不是通用性能保证。
合并后新构建再次验证 CMD 保存、关窗、连续两次重启，原命令和输出各保留一份。
此前单线程全量测试曾超时，默认并行全量通过；没有删除或新增忽略该测试。
