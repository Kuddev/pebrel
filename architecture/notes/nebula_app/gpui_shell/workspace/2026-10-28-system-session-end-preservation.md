# 系统退出期间保全工作区

## Status

提议，待上游审阅。2026-10-29 单窗口真实 Windows 关机恢复已验证；不代表多窗口或重复关机可靠性已验证。

## Context

系统关机可先结束终端，再结束 GUI。终端正常退出原本会移除对应标签，最后关闭空窗口。把这条正常交互链直接用于系统退出，会将完整恢复快照替换为空工作区。`clean_exit=true` 只表示最终保存原因，不证明标签和 AI 接续身份已保全。

不能通过禁止空存档修补：用户主动关闭最后一个标签必须仍然可以清空工作区，也不能让已主动结束的 Pi 在下次启动复活。

## Evidence

- 实际 Windows 关机记录中，存档在宿主退出前经历 5→3→0 标签，最终为空且标记正常退出；另一成功样本保留了标签。该对照解释本次直接丢档机制，不证明版本引入提交。
- 现有正常关闭路径会保存剩余标签，并在最后一个窗口关闭后保存空工作区；后续 Quit 使用该空 `latest`。
- 新的相邻产品测试先在原保存选择逻辑上失败，再由本补丁通过。覆盖快照缩减、AI 身份清理、取消、重复通知、写失败重试和管理员隔离。

## Decision

- 新增当前 UI 线程的 Windows 消息适配器，仅观察 `WM_QUERYENDSESSION` / `WM_ENDSESSION`，始终转发原消息，保持原窗口返回值；不注册全局 hook，不调用工作区或磁盘接口。
- Query 到达即标记待定；Query 被否决或收到取消的 EndSession 时解除；确认的 EndSession 保持保护。安装和卸载使用同一线程的生命周期 guard，安装失败显式报告。
- 继续由 [SessionPersistence](../../../../../nebula_app/src/gpui_shell/workspace/session_persistence.rs) 独占候选选择及写入。系统退出期间使用它已有的 `latest`，不接受终端拆除产生的缩减快照。没有既有快照时，只接受非空当前快照。
- 不增加保存副本、额外写线程、保存通道或会话格式。错误和管理员隔离继续走原策略。系统退出不设置普通 Quit 的永久冻结位，因此取消后可恢复常规保存。
- 非 Windows 平台的观察器为空实现，正常关闭候选规则不变。

## Rejected alternatives

- 永远保存最后一个非空快照：破坏主动关闭标签的语义。
- 只忽略 Pi 的结束事件：无法保住标签、目录和窗口布局。
- 独立关机写线程：产生另一条写入排序和权限隔离规则。
- 在原生消息回调中捕获 GUI 或同步写盘：增加重入、锁及销毁时序风险；现有保存器已持有周期采样结果。
- 提高周期保存频率或启动失败阈值：不解决已有完整快照被空状态覆盖的问题。

## Consequences

- 保护的是最后一次完整应用采样，而不是承诺重新读取所有终端的瞬时状态。通知前已按正常规则清掉的内容不会被补丁猜测恢复。
- 若系统终止应用而没有让 UI 线程处理通知，仍依赖原有周期 checkpoint；不能承诺恢复从未保存的内容。
- 关机取消后不重建已退出的终端；后续保存采用当时真实工作区。
- 原生回调只维护线程局部事实，不修改消息、系统退出顺序、安全控制或其他进程。

## Validation

- 相邻保存器测试：23 项通过，包含 11 项本次新增合同。
- 原生消息适配测试：4 项通过，验证先于接收方生效、原返回值不变、否决/取消、不同线程隔离、卸载与重复安装。
- 实际 GPUI/CMD/Pi：待定 Query 和已确认 EndSession 两轮，各验证 5 个 CMD（其中一个为合成 Pi）退出后仍保存 5 个标签；重开接续同一 Pi；取消后按 5→4→3→2→1→0 正常保存。4 次应用启动和专属 Job 均已回收。
- 全套应用测试：2770 通过、2 失败、46 原有忽略。两项失败在未修改的 f3201403 保存/平台/启动代码上同样复现：符号链接特权错误 1314、移动端设置按钮宽度断言。未删除测试、提高权限或扩大补丁修复其他模块；不能称全套通过。
- 上述应用测试和离线锁定构建在 f3201403 基线运行，格式和架构检查通过；移植到较新上游后的轻量检查不冒充新基线完整重编或重跑。
- 2026-10-29 用户执行一次真实 Windows 关机/开机：重开前后完整五标签和目录相等，五个真实 CMD 与新鲜子环境标记匹配，Pi 在宿主启动 2.336 秒后通过 --session 自动接续同一合成会话文件。真实多窗口关机及重复关机可靠性仍未验证，不以本轮结果推断版本引入提交。

## Supersedes

None。

## Revisit when

GPUI 提供等价的可靠系统退出生命周期入口时，优先替换这个薄原生适配器；需要跨线程保存或改变 Session 格式时，重新审阅当前线程事实和唯一保存权威，不追加平行写入通道。
