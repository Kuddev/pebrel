# Pebrel Android：HTML 还原与 Ghostty 迁移计划

更新：2026-09-16。

本计划按用户明确要求执行：高性能、可扩展；替换 Termux 终端库，采用 Ghostty；
先做出指定 HTML 的样子。由主 agent 单独实施，不再启动子 agent。
本文件记录计划和实际完成状态，未勾选项目不能写成已交付。

## 目标与顺序

1. **先完成主要界面还原**，让安装包具有已确认原型的页面结构、比例、配色和交互。
2. **将 Android 产品依赖切换为 Ghostty**，保留真实 SSH、本地终端及电脑连接能力。
3. **完善桌面输出和断线恢复**，降低延迟和无效传输，保证同会话接力。
4. 通过新源码的构建、行为测试、模拟器截图及性能检查后交付新 APK 和配套说明。

视觉唯一基准：`/mnt/d/temp_build/nebula/pebrel-mobile-prototype.html`。
按该文件最终 CSS/JavaScript 渲染结果实现，不使用旧 focus draft 或早期页面截图。
原型中旧底导航已被最终 render 隐藏，不能将其重新当作当前设计。

## 已确定的技术方向

| 层 | 选择 | 职责 |
| --- | --- | --- |
| 产品界面 | Kotlin、Jetpack Compose | 导航、主机/设备、设置、命令编辑和任务信息 |
| 终端状态 | 源码构建的 libghostty-vt | VT 解析、屏幕、回滚、样式、输入编码、模式 |
| Android 桥接 | Android NDK、JNI、薄 C/C++ 适配 | 以批次交换字节与渲染数据，管理 native 生命周期 |
| 终端渲染 | Android 原生 View / Canvas / HWUI | Ghostty 脏行快照；系统字体塑形、回补和 GPU 字形缓存；按需绘制 |
| 会话与异步 | Kotlin coroutines / StateFlow | 会话身份、取消、恢复及旧回调隔离 |
| SSH | russh 0.62.2、Tokio、独立 JNI 模块 | 加密字节流、主机身份核对、PTY resize |
| 桌面连接 | 保留 OkHttp/WebSocket 与 Rust Runtime | 操作电脑已有 Pane；扩展为有序输出订阅 |
| 凭据 | Android Keystore 与现有加密存储 | 凭据存储和主机身份；不混入 UI/渲染层 |

Ghostty 初始核验 revision：`28f9367bee11ad42f40f8aa589eb8c6db62d34be`。
其 Android VT 构建已有 NDK 路径和 16 KiB page-size 设置，但完整 Android 控件仍需
由本项目适配。固定依赖 revision 和构建工具版本，记录来源、许可证与升级条件。
不使用私有预编译库。

### 社区评论的可用结论

| 评论中的现象或需求 | 本项目采用的方向 | 证据边界 |
| --- | --- | --- |
| 手机需要继续电脑正在做的工作 | 同一个 workspace/pane/task 身份；手机离线不结束电脑任务 | 新开 SSH shell 或远程桌面本身不保证同会话接力 |
| Tailscale 显示已连接，App 仍反复重连 | 区分网络可达、电脑在线、应用配对及会话同步；提供对应失败状态 | VPN 状态不能证明应用 socket 有效或链路正在 P2P 直连 |
| 杀掉 App 再打开更容易成功 | 检查前后台恢复、切网失效 socket、重试取消、旧回调隔离 | 这是排查线索，评论不足以确定产品内部根因 |
| 蒲公英虚拟局域网在某些国内线路更快 | 保持网络可替换；先验证软件组网与已有连接路径 | 不承诺普遍秒连；免费设备数、带宽和价格需以当期官方条款为准 |
| 用户只需查看输出、回复少量文字 | 当前 Pane 按需订阅、首次快照后传增量、后台停止无效刷新 | 文字终端也可能高吞吐，仍需有界队列、流控及实测 |
| SSH + tmux/herdr 对部分人足够 | 保留独立 SSH 路径，不强迫所有用户部署中转 | tmux 不能自动接管未在其中运行的已有 Pebrel Tab |

不因评论中的推荐数量扩张技术栈。远程桌面、IM bot、VPN、终端内核分别承担不同
职责；当前优先保证同会话身份、输入归属、原生界面和可恢复连接。Ghostty 不承担
网络重连职责，也不能以更换内核代替上述验证。

Compose 不参与逐格绘制；只有一个终端状态权威。原生内核不会把所有 cell 转为
Kotlin 对象或逐字发起 JNI 调用。先明确字形塑形、字体回补与 native 缓存的所有权，
再固定所需字体依赖；不能用只显示 ASCII 的 renderer 代替完整迁移。

### 2026-09-16 接入实施决策

用户要求下一包必须已经接入 Ghostty 并去掉 Termux 产品依赖。先前界面包不单独交付。
采用系统 HWUI 的原生 View 绘制，不额外引入私有 EGL 引擎、Rust 运行时或重复字体库。
Ghostty 负责 VT、宽度、回滚和按终端模式编码按键；JNI 按脏行传 UTF-16 文本及扁平
样式数组，Android 字体系统负责塑形和字体回补。终端解析/快照在后台串行状态通道执行，
UI 只消费不可变快照；输入队列有字节预算，输出读取通过挂起施加背压。离开页面不定时
生成快照，关闭会话取消 I/O 并释放 native 状态。系统 View/HWUI 管理绘制资源生命周期，
无需自行持有 EGL context。自定义 GPU 管线以实际性能瓶颈为前提，不能虚称本版已实现。
旧 Termux 源码和测试暂留为显式启用的历史回归资料，应用依赖图及 APK 不再包含它们。

## 阶段 A：优先还原 HTML

- [ ] 在浏览器核对首页、主机页、电脑页、终端页、设置页以及深浅主题。
- [ ] 建立原型对应的字体层级、间距、细分隔线、克制圆角、图标与命中区域。
- [ ] 首页：横向会话缩略图、真实主机与电脑分区、添加 SSH 入口、本地终端入口。
- [ ] 会话缩略图：只取真实内容的有界快照；空状态也有完整布局；不编造终端输出。
- [ ] 主机页：搜索、主机行、详情/编辑、添加表单、密码与主机指纹确认。
- [ ] 电脑页：设备信息、真实 Tab/Pane 列表、连接状态及断开/恢复入口。
- [ ] 终端页：会话切换标题、上下文、输出区、本地命令编辑、发送、辅助键和长命令编辑。
- [ ] 候选点击只填草稿；发送成功才清除对应草稿；切换会话不串内容。
- [ ] 设置页：按原型分组组织主题、字体、输入、连接/通知/后台能力。
- [ ] 英文和简中文案对应；失败、加载、禁用、选中与成功状态可辨认。
- [ ] 模拟器验证窄屏、键盘弹出、返回、表单取消、重复点击和主题切换，保存真实截图。

此阶段复用现有数据和连接能力。若先生成界面预览 APK，清楚标明其内核状态；
最终 Ghostty 包必须在阶段 B 完成后重新构建。二维码、文件/语音、WebDAV 和结构化
阅读等尚未实现的能力不得显示虚假成功。具体未接通项应明确状态，避免空操作按钮。

## 阶段 B：Termux → Ghostty

- [ ] 增加可复现的 Ghostty 源码获取/校验/构建流程，支持 arm64-v8a 与 x86_64。
- [ ] 构建 Android terminal 模块，连接 Ghostty C API，检查 native 符号与内存所有权。
- [ ] 实现字节写入、resize、颜色/光标、屏幕与回滚、选区和有界文本提取。
- [ ] 实现原生渲染表面：字形缓存、脏更新、按需绘制、GPU context 销毁与重建。
- [ ] 接入中文 IME 预编辑、emoji/组合字符、物理键盘、辅助键及 bracketed paste。
- [ ] 保留本地 PTY 与 SSH 传输的有界队列、取消、关闭及发送失败反馈。
- [ ] 会话不依赖 Activity 存活；页面离开释放绘制资源，保留合理的会话状态。
- [ ] 替换应用中的 Termux TerminalSession/TerminalView/TerminalColors 等依赖与调用。
- [ ] 更新产品 Gradle 依赖、资源生成、第三方说明和源码交付说明。
- [ ] 核查 APK 的 dex/native 内容，确认不再携带 Termux emulator/view 产品依赖。
- [ ] 原有功能合同迁移到新内核测试；保留旧回归资料，不通过删测试来取得绿色结果。

Ghostty 自身不提供 SSH 或电脑会话接力。内核迁移与网络恢复分别验证，
不能将换库写成已经获得网络漫游能力。

## 阶段 C：桌面同步与连接恢复

- [ ] 统一连接状态：连接中、可用、恢复中、不可达、认证失败、主动断开。
- [ ] 监听前台恢复与网络变化，及时淘汰失效 socket；重试有退避、抖动和取消。
- [ ] 回调绑定 connection generation，旧回调不能覆盖新连接。
- [ ] 保留 workspace/pane 身份与草稿，重连只恢复状态；执行结果未知的输入不自动重发。
- [ ] 只订阅当前可见 Pane，离开或进入后台停止对应输出工作。
- [ ] 最终采用首次快照、有序增量、流控和有界恢复，支持真实终端行为。
- [ ] 旧 Runtime 的文本 tail 路径保留兼容；changed-only 采样只作为过渡，明确能力差异。
- [ ] 明确手机与电脑的输入和 viewport 所有权，避免阅读手机时意外改变电脑 TUI 尺寸。
- [ ] 后台保持由用户开启；手机断开不终止电脑任务。

自建 WSS 继续使用证书校验。当前 TLS 在中转终止；端到端加密、持久离线通知和
独占输入权限尚不属于已完成能力，不能随界面迁移宣称已经支持。

## 验收标准

### 功能与视觉

- [ ] HTML 与真实 Android 截图逐页面核对：结构、比例、颜色、文字层级、键盘与空状态。
- [ ] SSH 登录、主机指纹、中文输入、发送、长输出、选区复制、多会话草稿隔离可用。
- [ ] vim/htop 等全屏应用、颜色、宽字符、resize、alt-screen、鼠标/辅助键按支持范围验证。
- [ ] 网络失败、主动关闭、后台切换、重连及旧回调不破坏任务和输入归属。

### 性能与资源

- [ ] 固定设备、release/preview 优化模式、字体、列行和回滚数量比较迁移前后。
- [ ] 分开测 VT 解析吞吐、帧时长/掉帧、本地输入到显示 p50/p95/p99、CPU。
- [ ] 记录 Java/native/graphics/PSS，覆盖 1/5/20 会话与重复打开关闭后的资源回收。
- [ ] 无变化时停止输出绘制；后台不保持终端动画；缩略图不各开全速 renderer。
- [ ] 以固定 RTT、丢包和切网场景测试网络首屏、命令确认和恢复，避免误归因给 renderer。

正确性是性能比较的前提。缺字、丢输出、删回滚或禁用功能得到的更快结果不合格。
未做真机测量时不声称已经更省电、更省内存或达到某个延迟数字。
