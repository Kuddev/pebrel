# Pebrel 2.2.3

## English

### Fixed

- Fixed: Holding Alt while dragging a tab and releasing now tears it into a standalone new window from anywhere inside the window, including when the window fills the screen and with left-sidebar tabs. The sidebar tear-out previously only triggered when the cursor left the window bounds, which a maximized single-screen laptop window never allows, so the tab appeared stuck and snapped back on release. Addresses [#572](https://github.com/Kuddev/pebrel/issues/572).
- Fixed: Drag releases that land outside the source window are no longer silently dropped. Releasing a dragged tab over another Pebrel window merges it there, with a live dock preview in the target window while hovering, and releasing past the window edge tears the tab into a new window. Addresses [#572](https://github.com/Kuddev/pebrel/issues/572).

## 中文

### 修复

- 修复：拖动标签时按住 Alt 再松手，现在可从窗口内任意位置把标签撕成独立新窗口，包括窗口铺满屏幕以及使用左侧栏标签的情形。此前侧栏撕出只在光标移出窗口边界时触发，而最大化的单屏笔记本窗口无法让光标移出，导致标签看起来“拖不动”并在松手后弹回原位。对应 [#572](https://github.com/Kuddev/pebrel/issues/572)。
- 修复：落在源窗口之外的拖拽释放不再被静默丢弃。把标签拖到另一个 Pebrel 窗口上松手会合并进该窗口，悬停期间目标窗口实时显示 dock 高亮预览；向窗口边缘外拖出松手会把标签撕成新窗口。对应 [#572](https://github.com/Kuddev/pebrel/issues/572)。
