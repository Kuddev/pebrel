# Pebrel 2.6.2

## English

macOS, Linux, and Android downloads are Preview builds.

### Fixed

- Fixed a delegated prompt remaining in the terminal editor when the agent changed keyboard mode before Enter was sent.
- Fixed delegated Claude Code tasks reporting that no final message was available even when Claude supplied an answer.
- Fixed a reply from a worker’s previous turn being returned for a newly delegated task.
- Fixed WSL worker replies failing to reach the pane that delegated the task.
- Fixed SSH panes retaining the Codex identity after exit when the remote Bash prompt displayed a changing clock.
- Fixed restoring the previous conversation after `/new` in a standalone Codex client. When the pane holds both threads, Pebrel matches the full thread ID beneath the empty prompt. If it cannot identify the current thread, it offers the Codex picker on restart.
- Fixed errors from `ls Env:` and preserved PowerShell provider objects for pipeline commands. Addresses [#1063](https://github.com/Kuddev/pebrel/issues/1063).
- Fixed Shift+Home and Shift+End scrolling the terminal when selecting text at a local PowerShell prompt. Addresses [#1052](https://github.com/Kuddev/pebrel/issues/1052).
- Fixed a second title bar appearing above Pebrel on KDE Wayland. Addresses [#1044](https://github.com/Kuddev/pebrel/issues/1044).
- Fixed split panes falling back to Windows PowerShell when the default shell was an imported profile such as Niubash. Addresses [#1074](https://github.com/Kuddev/pebrel/issues/1074).

## 中文

macOS、Linux 和 Android 下载为预览版。

### 修复

- 修复 Agent 在接收委派内容后切换键盘模式，导致回车未提交、指令留在输入框的问题。
- 修复 Claude Code 已经给出最终答复，发起委派的窗格却显示没有最终消息的问题。
- 修复新任务刚被委派时，调用方可能收到上一轮答复的问题。
- 修复 WSL 中的 Agent 完成任务后，发起委派的窗格收不到答复的问题。
- 修复远端 Bash 提示符的时钟变化后，退出 Codex 的 SSH 窗格仍显示 Codex 身份的问题。
- 修复独立运行的 Codex 在 `/new` 后恢复旧对话的问题。窗格同时持有新旧两份记录时，Pebrel 会核对空输入框下方显示的完整对话 ID。无法确认时，重启后可在 Codex 中选择对话。
- 修复 PowerShell 执行 `ls Env:` 时逐项报错的问题，查询结果可继续传给管道命令。 对应 [#1063](https://github.com/Kuddev/pebrel/issues/1063)。
- 修复在本地 PowerShell 输入行按 Shift+Home 或 Shift+End 选中文字时，终端滚动到顶部或底部的问题。 对应 [#1052](https://github.com/Kuddev/pebrel/issues/1052)。
- 修复 KDE Wayland 上 Pebrel 窗口顶部出现双标题栏的问题。 对应 [#1044](https://github.com/Kuddev/pebrel/issues/1044)。
- 修复将 Niubash 等导入配置设为默认 Shell 后，新分屏仍回退到 Windows PowerShell 的问题。 对应 [#1074](https://github.com/Kuddev/pebrel/issues/1074)。
