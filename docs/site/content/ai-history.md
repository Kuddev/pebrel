## 找到之前的对话

按 **Ctrl+Shift+O**（macOS 为 **⌘⇧O**）打开快速跳转，输入会话标题、项目目录或相关关键字。列表按工具分组，同一次对话可能列出两种操作：**恢复**会接回原对话，**分叉**（仅部分工具提供）会从原对话的上下文开出新对话。每一行会显示工具名称、位置和时间，先核对工具类型和目录，再选择。

Pebrel 会尝试使用工具的会话记录打开对话。CLI 出现后，确认上下文确实属于原任务，再输入新的问题。

历史列表会读取 Claude Code 和 Codex 自己保存的会话记录；其他已启用 Agent 集成的工具，会在它们上报会话之后出现在列表里。没有集成的工具，请通过工具自己的恢复入口打开。各工具是否支持恢复与分叉，见[支持的 AI 命令行工具](agents.md)。

## 每次启动时自动接续

在 **设置 → 高级 → 会话生命周期**开启：

- **启动时恢复上次标签**；
- **恢复时接续 AI 对话**。

正常退出后重开 Pebrel，检查对应终端是否恢复了原对话。需要原会话记录、有效的身份信息，以及可用的 CLI 安装。

关闭 Pebrel 时，如果还有 AI 对话没有取得身份信息，会弹出"仍有 AI 会话未能识别，继续关闭？"。选择 **保存已知状态并关闭** 会保存布局和已知的对话；没取得身份的对话，下次打开时可能需要手动选择。刚启动的工具需要一点时间取得身份，等它们启动完成后再关闭，可以避免这个提示。

能否自动接回，取决于工具是否在[支持列表](agents.md)里有"恢复对话"的 ✓。

## 恢复失败或需要选择会话

原对话没能接上时，Pebrel 会保留原来的恢复记录，不会丢掉。右键相关终端标签，使用当前可用的 **重试会话恢复** 或 **选择要继续的对话…**。

先检查项目目录是否仍存在、CLI 是否需要重新登录，以及原工具的历史记录是否还在。记录不足时，可以打开工具自己的历史选择器查找；Pebrel 列表没有显示某条记录，并不意味着工具已经删除它。

## 从已有上下文分出新对话

在受支持的本地会话中，右键标签选择 **分叉 AI 会话**；也可以在历史列表里，对某次旧对话选择 **分叉**。目前 Claude Code、Codex、OpenCode、Kimi Code、Pi、Oh My Pi 和 Grok 可以分叉。新会话从已有上下文开始，原对话继续保留。

这个入口要求 Pebrel 已识别工具和会话身份；SSH、自定义 Profile 或身份信息不完整时可能不显示。需要分叉时，先在受支持的本地 Shell 中建立会话。

对话分叉沿用上下文，但不会自动给代码建立独立工作目录。准备并行修改文件时，使用[Git worktree](agent-worktrees.md)。

## 使用已知会话 ID

已经从工具取得有效 ID 时，也可以在相应环境中运行它的恢复命令。将 `SESSION_ID`换成真实值：

```sh
claude --resume SESSION_ID
```

或：

```sh
codex resume SESSION_ID
```

安装的 CLI 版本需要支持相应命令。CLI 报参数错误时，先查看该版本的帮助，而不是反复尝试同一命令。

## 备份对话

保存 Pebrel 布局或主机列表不会同时备份所有 CLI 的对话正文。换电脑或清理历史前，按工具自己的方式备份会话记录，并保留对应项目目录。
