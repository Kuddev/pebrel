## 找到之前的对话

按 **Ctrl+Shift+O**（macOS 为 **⌘⇧O**）打开快速跳转，输入会话标题、项目目录或相关关键字。在历史结果中核对工具类型和目录，再选择要继续的会话。

Pebrel 会尝试使用工具的会话记录打开对话。CLI 出现后，确认上下文确实属于原任务，再输入新的问题。

当前已有受支持的 Claude Code 与 Codex 恢复流程。其他 CLI 的历史可以通过工具自己的恢复入口打开。

## 每次启动时自动接续

在 **设置 → 高级 → 会话生命周期**开启：

- **启动时恢复上次标签**；
- **恢复时接续 AI 对话**。

正常退出后重开 Pebrel，检查对应终端是否恢复了原对话。需要原会话记录、有效的身份信息，以及可用的 CLI 安装。

## 恢复失败或需要选择会话

右键相关终端标签，使用当前可用的 **重试会话恢复**或 **选择要继续的对话…**。

先检查项目目录是否仍存在、CLI 是否需要重新登录，以及原工具的历史记录是否还在。记录不足时，可以打开工具自己的历史选择器查找；Pebrel 列表没有显示某条记录，并不意味着工具已经删除它。

## 从已有上下文分出新对话

在受支持的本地 Claude Code 或 Codex 会话中，右键标签选择 **分叉 AI 会话**。新会话从已有上下文开始，原对话继续保留。

这个入口要求 Pebrel 已识别工具和会话身份；SSH、自定义 Profile 或身份信息不完整时可能不显示。需要分叉时，先在受支持的本地 Shell 中建立会话。

对话分叉沿用上下文，但不会自动给代码建立独立工作目录。准备并行修改文件时，使用[Git worktree](agent-worktrees.md)。

## 使用已知会话 ID

已经从工具取得有效 ID 时，也可以在相应环境中运行它的恢复命令。将 `SESSION_ID`换成真实值：

```sh
claude --resume SESSION_ID
```

或：

```sh
codex resume SESSION_ID
```

安装的 CLI 版本需要支持相应命令。CLI 报参数错误时，先查看该版本的帮助，而不是反复尝试同一命令。

## 备份对话

保存 Pebrel 布局或主机列表不会同时备份所有 CLI 的对话正文。换电脑或清理历史前，按工具自己的方式备份会话记录，并保留对应项目目录。
