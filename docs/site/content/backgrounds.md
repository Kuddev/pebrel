## 设置一张背景图片

1. 打开 **设置 → 外观 → 自定义背景**。
2. 在 **背景图片**中选择本机图片文件。
3. 设置 **背景图像拉伸模式**和 **背景图像对齐**。
4. 调低 **背景图像不透明度**，让文字不被图片干扰。
5. 回到终端检查普通输出、彩色输出和选区的清晰度。

图片默认位于终端文字后方。要将图片延伸到标题栏和侧栏，开启相应的覆盖选项，并阅读确认提示。

## 选择铺放方式

| 模式 | 效果 | 适合的情况 |
| --- | --- | --- |
| **拉伸** | 铺满区域，可能改变图片比例 | 纹理或不怕变形的图案 |
| **适应** | 保持比例，完整显示，可能留空 | 希望看见整张图片 |
| **填充** | 保持比例铺满，可能裁剪边缘 | 壁纸铺满终端 |
| **原始尺寸** | 不缩放图片 | 按原图尺寸放置 |

主体被裁掉时，在九个对齐位置中选择顶部、左侧、居中等位置，再调整窗口大小查看结果。

## 调整图片与终端透明度

**背景图像不透明度**越低，图片越淡。**终端正文不透明度**控制终端背景整体的不透明程度，100% 为完全不透明。

两者可以分别调整。例如，希望有一张浅淡壁纸、但不透出桌面，可以降低图片不透明度，同时把终端正文不透明度保持为 100%。设置页本身不会按终端正文透明度变化。

## 选择背景模糊

在 **外观 → 界面 → 背景模糊**中选择当前平台可用的窗口效果。Mica、Aero 和 Acrylic 等效果依赖 Windows 与系统环境，不同系统不会呈现完全相同的材质。

出现闪烁、文字难读或窗口拖动不流畅时，先选择“无”并提高不透明度，再逐项恢复效果。

## 更换或移除图片

重新选择其他图片可以替换背景；需要回到纯色效果时，点击 **背景图片**行的重置按钮移除图片，再选择主题背景色。

图片被移动、所在磁盘未挂载或路径失效时，重新选择可读取的文件。迁移到另一台电脑时，把图片素材单独复制过去，并更新路径。
