## 常用操作

下表列出默认按键。**⌘**是 Command，**⇧**是 Shift，**⌥**是 Option。已经自定义过快捷键时，以 **设置 → 按键映射**中显示的内容为准。

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 新建标签页 | Ctrl+Shift+T | ⌘T |
| 新建窗口 | Ctrl+Shift+E | ⌘N |
| 关闭当前项 | Ctrl+Shift+W | ⌘W |
| 打开设置 | Ctrl+, | ⌘, |
| 显示或隐藏侧栏 | Ctrl+Shift+B | ⌘B |
| 命令面板 | Ctrl+Shift+P | ⌘⇧P |
| Shell 选择器 | Ctrl+K | ⌘K |
| 快速跳转 | Ctrl+Shift+O | ⌘⇧O |
| 文件树 | Ctrl+Shift+F | ⌘⇧F |
| 版本控制面板 | Ctrl+Shift+G | ⌘⇧G |
| 向右分屏 | Ctrl+Shift+D | ⌘D |
| 向下分屏 | Ctrl+Shift+S | ⌘⇧D |
| 放大或还原窗格 | Ctrl+Shift+Enter | ⌘⇧Enter |
| 切换相邻窗格 | Ctrl+Alt+方向键 | ⌘⌥方向键 |
| 下一个 / 上一个标签 | Ctrl+Tab / Ctrl+Shift+Tab | ⌘⇧] / ⌘⇧[ |
| 增大 / 减小终端字号 | Ctrl++ / Ctrl+- | ⌘+ / ⌘- |
| 重置终端字号 | Ctrl+0 | ⌘0 |
| 全屏 | Alt+Enter | ⌘Ctrl+F |

复制、粘贴和滚动见[剪贴板](clipboard.md)与[终端基础操作](terminal-basics.md)。文档编辑按键见[Markdown 编辑](markdown-editing.md)。

## 更改一个快捷键

1. 打开 **设置 → 按键映射**。
2. 找到要更改的动作，进入按键录入状态。
3. 按下新的组合键，检查界面显示的结果。
4. 返回工作区，在相应位置测试。

录入时按 **Esc**取消；使用界面提示的清除操作或 Backspace 清除当前录入。出现冲突提示时，换一个组合键，或先调整原来占用它的动作。

## 同一按键在不同位置的作用

快捷键会受当前焦点影响。例如，编辑 Markdown 段落时 **Ctrl+B / ⌘B**用于加粗选区；搜索框里的方向键用于选择结果，而不是移动终端光标。

快捷键没有按预期生效时，先点击要操作的终端或文档，再试一次。系统级快捷键也可能先被桌面环境或其他应用接收。

## Windows 全局快速终端

全局热键可在 Pebrel 不处于前台时使用，配置入口位于按键映射相关设置中。设置后，切换到其他应用试按一次，检查是否成功唤起窗口。

热键无法注册时，改用没有被其他应用占用的组合。详细设置见[快速终端与托盘](quick-terminal.md)。

## 恢复默认按键

设置页底部的 **恢复默认设置**会同时恢复设置与快捷键，并备份原设置；SSH 主机、凭据和历史会保留。需要只改一个动作时，优先调整该项，避免重置其他个性化设置。
