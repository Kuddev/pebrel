## 打开设置并查找选项

按 **Ctrl+,**（macOS 为 **⌘,**），或点击工作区的设置按钮。

顶部搜索可以查找设置所属的分区。例如输入“通知”进入提醒相关设置，输入“字体”进入外观，输入“恢复”查找会话生命周期。搜索无结果时，试用更短的关键字。

## 设置什么时候生效

开关和选择项通常在操作后保存。文字输入按相应字段提示，通过 Enter、离开输入框或保存按钮提交。

有些设置影响新会话：更改默认 Shell、回滚行数或终端代理环境后，新建窗格检查效果。修改 Agent 集成后，重新启动相应 CLI。

出现保存失败提示时，按错误信息检查文件或目录权限，不必删除整套配置。

## 更改界面语言

在 **外观 → 界面 → 语言**选择需要的语言。设置改变 Pebrel 的菜单和说明文字，不改变 Shell 或远端程序输出。个别未翻译项会显示英文。

## Windows 登录时启动

在 **高级 → 会话生命周期**中开启 **登录时自启动**。希望启动后先在后台待命时，再开启 **静默启动**；启用时会同时启用托盘，可从托盘重新打开窗口。

显式打开目录等启动方式可能仍会显示窗口。先测试一次普通启动和托盘唤回，再决定是否保留静默模式。

## 找不到平台专有选项

托盘、全局快速终端、登录启动和关窗保留后台会话目前是 Windows 集成。macOS 和 Linux 不显示对应选项时，可以按各平台已有的窗口和会话恢复方式使用。

修改配置文件、备份偏好和恢复默认设置，分别见[Lua 配置](configuration.md)、[备份迁移](migration.md)和[交互设置](interaction.md)。
