## 打开保存命令

点击工作区顶栏的**闪电图标**打开命令管理器。先点击准备接收命令的终端窗格，再打开管理器；选中的条目会发送到这个终端。

搜索框可以查找命令名称或命令文字。列表同时提供内置条目和你自己保存的条目。

## 保存第一条命令

例如，把检查 Git 工作区状态的命令保存下来：

1. 点击 **新增命令**。
2. **名称**填写“查看项目改动”。
3. **命令**填写 `git status --short`。
4. 暂时不勾选 **插入后立即按 Enter 执行**。
5. 点击 **保存**。

回到一个 Git 项目的终端，再次打开管理器并选择这条命令。文字会插入输入区，你可以先检查目录，再按 Enter 执行。

## 插入文字，还是立即执行

| 使用方式 | 适合的条目 |
| --- | --- |
| 不勾选立即执行 | 需要补充参数、路径或检查后再运行的命令 |
| 勾选 **插入后立即按 Enter 执行** | 不需要补充参数的常用命令 |

开启立即执行时，选择条目会同时发送回车。多行条目会将各非空行整理后用 `; ` 连接再执行；需要保留原始换行的脚本，请保存成脚本文件，或关闭立即执行后按目标程序的要求处理。

> [!WARNING]
> 开启立即执行的命令会在当前终端直接运行。对删除、部署或生产环境命令，建议保留插入后确认的方式。

## 用分组整理命令

点击 **新建分组**并输入名称，例如“项目开发”或“服务器维护”。打开命令条目的菜单，使用 **移到分组**选择目标分组。

进入一个分组后，可以使用 **返回全部命令**查看完整列表。将条目移出分组时选择 **移出分组**。选择 **删除分组，保留其中的命令**只会移除分组，命令仍可在列表中找到。

## 修改内置命令

内置命令提供 Git、Docker、Python 和常见开发工具的示例。要调整其中的参数，打开条目菜单，选择 **保存副本**，然后编辑自己的副本。

内置条目会根据当前终端环境筛选。使用前仍需在这个环境中安装相应工具，例如 Docker 命令需要 Docker 可用。

## 编辑和删除

从自己的命令条目菜单打开 **编辑命令**，修改名称、内容或执行方式后保存。删除不再使用的条目前，确认选中的是自己的那一条。

密码、Token 和临时验证码应在终端或凭据提示中输入，不要长期放进命令条目。迁移命令库时，见[备份与迁移](migration.md)。
