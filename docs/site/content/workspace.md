## 窗口、标签页和窗格

一个 Pebrel 窗口可以容纳多个标签页。终端标签页里又可以分成多个窗格，每个窗格都有自己的 Shell、当前目录和运行中的程序。

例如，可以为两个项目分别建立标签页，在每个标签页里分出“运行服务”和“查看日志”两个窗格。切换项目时切换标签页；同时查看输出时使用分屏。

## 创建和切换标签页

点击新建终端入口，或按 **Ctrl+Shift+T**（macOS 为 **⌘T**）。需要为新终端选择不同 Shell 时，使用 **Ctrl+K / ⌘K** 打开 Shell 选择器。

点击标签即可切换。也可以使用 **Ctrl+Tab** 切到下一个标签、**Ctrl+Shift+Tab** 切到上一个标签；macOS 还支持 **⌘⇧] / ⌘⇧[**。

在 **设置 → 交互** 中，**标签栏位置**可选择“左侧边栏”或“顶部”，**新标签位置**可选择“当前标签之后”或“列表末尾”。

## 创建分屏

1. 点击准备拆分的终端窗格。
2. 右键标签页，选择 **左右分屏**或**上下分屏**。
3. 新窗格出现后，点击它并运行需要的命令。

快捷键：Windows / Linux 使用 **Ctrl+Shift+D** 向右分屏、**Ctrl+Shift+S** 向下分屏；macOS 使用 **⌘D / ⌘⇧D**。

拖动分隔线可以改变两个窗格的大小。需要暂时集中看一个窗格时，按 **Ctrl+Shift+Enter / ⌘⇧Enter** 放大当前窗格，再按一次还原布局。

## 在窗格之间移动

点击窗格可以将输入焦点移过去。使用键盘时，按 **Ctrl+Alt+方向键**（macOS 为 **⌘⌥方向键**）切换到相邻窗格。

拖动窗格标题可以调整排布；将标题拖出终端区域，可以把该窗格拆成独立标签。拖动前先辨认窗格标题与分隔线：前者移动窗格，后者调整大小。

## 重命名、排序和标色

右键标签页打开菜单：

| 操作 | 用途 |
| --- | --- |
| **重命名** | 输入项目名或用途，例如“API 日志”；也可使用 F2 |
| **向左移动 / 向右移动** | 调整标签顺序；位于边缘时，对应方向不可用 |
| **标签颜色** | 用颜色区分项目或环境；选择清除项可恢复默认 |
| **移到新窗口** | 将这项工作移到单独窗口中 |
| **复制标签** | 用同类启动入口新建会话，并尽量沿用已知工作目录 |

“复制标签”适合在同一目录再开一个 Shell；原终端里正在运行的命令仍留在原标签中。

## 收起侧栏

点击侧栏收起按钮，或按 **Ctrl+Shift+B / ⌘B**。打开文件树时使用 **Ctrl+Shift+F / ⌘⇧F**。终端区域需要更多空间时，可以收起不使用的面板。

如果经常使用同一套排布，打开命令面板搜索“布局”，将当前标签或窗口保存为[布局配方](layouts.md)。

## 关闭终端

在 Shell 中输入 `exit`，或使用关闭入口。关闭前先停止仍需处理的命令，并保存文档标签中的修改。有关 Windows 关窗后保留任务、重启后恢复标签的设置，见[会话保存与恢复](sessions.md)。
