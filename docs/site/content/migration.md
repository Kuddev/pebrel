## 找到个人数据目录

| 系统 | 标准位置 |
| --- | --- |
| Windows | `%APPDATA%\Pebrel` |
| macOS | `~/Library/Application Support/Pebrel` |
| Linux | `$XDG_CONFIG_HOME/pebrel`，未设置时通常为 `~/.config/pebrel` |

Windows 可以把路径粘贴到资源管理器地址栏；macOS 可在 Finder 的“前往文件夹”中输入路径。使用 `PEBREL_CONFIG_DIR`时，以指定目录为准。

## 备份哪些内容

先正常退出 Pebrel，再复制个人数据目录到安全位置。常见文件包括：

| 内容 | 文件或位置 |
| --- | --- |
| 界面偏好和快捷键 | `pebrel_settings.txt` |
| 保存的常用命令 | `saved_commands.json` |
| 最近会话布局 | `session.json` |
| SSH 配置记录 | `ssh_profiles.json`，及主机库的相关数据 |
| Lua / TOML 终端配置 | 实际加载的 `pebrel.lua`或对应配置文件 |
| 背景、额外字体和主题素材 | 保留使用中的素材及其路径 |

整目录备份适合自己的恢复用途。需要发给别人或上传仓库时，改为挑选必要的脱敏文件，排除凭据、历史敏感信息及 `runtime.port`等运行时发现文件。

## 迁移到另一台电脑

1. 在旧电脑退出 Pebrel，备份数据与自定义配置。
2. 在 SSH 主机库导出 CSV，需要分享或单独迁移的主题使用主题导出。
3. 在新电脑安装 Pebrel、常用 Shell、字体和 AI CLI。
4. 放回需要的个人配置，修正旧电脑上的程序和项目路径。
5. 重新配置系统凭据、私钥位置和需要的账户登录。
6. 新建终端、连接一台主机，再检查命令库和布局。

跨系统迁移时，不要直接沿用另一系统的绝对路径。主题颜色通常可保留，字体、壁纸和 Shell 路径需要在新系统中重新确认。

## SSH 密码与私钥

CSV 只包含地址、名称和分类信息，不携带密码、私钥或私钥口令。系统凭据库中的内容也不会通过复制应用目录自动迁移。

私钥应使用安全方式单独迁移，并保持恰当的访问权限；在新电脑上编辑主机条目，重新选择私钥并测试连接。不要把私钥放进公开仓库或普通分享压缩包。

## 从 Nebula 升级

Pebrel 会在新位置缺少相应文件时尝试复制旧版数据，保留旧文件，不覆盖已有 Pebrel 数据。首次启动后先检查主题、主机和命令，再清理旧环境。

新旧配置同时存在时，检查实际加载的文件。使用 `pebrel config check`可以发现语法问题；配置选择规则见[Lua 配置](configuration.md)。

## 还原备份

先退出应用并保留当前数据副本，再恢复准备使用的文件。不要恢复旧的运行时控制端口或 Token 文件；让新进程自行建立。

恢复后检查目录权限，运行配置检查，再新建终端验证。AI CLI 的对话正文需要按各工具自己的方式备份和恢复，不包含在 Pebrel 的标签布局中。
