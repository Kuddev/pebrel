## 查找一台主机

打开 **设置 → SSH**，在搜索框输入名称、地址、分组、标签或备注。经常使用的主机可以置顶，方便从列表找到。

建议用用途命名条目，例如“开发环境”或“日志服务器”；同一地址的不同账户，也可以在名称中写明账户用途。

## 编辑连接和分类

打开条目的编辑入口，在 **基本**页修改地址、端口、用户名或认证方式。分组、标签和备注用于整理列表，可以填写环境、项目和用途。

保存前检查地址与用户名，再使用 **测试连接**确认。如果只想更改列表显示文字，修改 **主机名称**即可，不必改服务器地址。

## 使用 SSH config 中的主机

Pebrel 可以发现用户 SSH config 文件中的别名。修改配置后，使用列表的重新读取入口刷新。

从配置文件发现的主机可以在 Pebrel 列表里隐藏；这不会删除原 SSH config 条目。要重新显示，使用隐藏项的恢复入口。如何编写别名和 IdentityFile，见[使用 SSH config](ssh-config.md)。

## 导出主机列表

在 SSH 主机库的导出入口选择 CSV 文件位置。导出的连接元数据包含以下列：

```csv
destination,label,group,tags,notes
dev@example.com,开发服务器,开发环境,linux;test,测试账户
```

CSV 不包含密码、私钥内容或私钥口令。它适合备份地址与分类，或在另一台电脑上重建主机列表。

## 批量导入主机

1. 先从 Pebrel 导出一份 CSV，保留列名作为模板。
2. 在副本中填写地址、显示名称及分类信息。
3. 使用导入入口选择文件。
4. 查看导入结果，确认新增、跳过或失败的条目。
5. 为新增主机补充认证信息，再测试连接。

已有条目不会被导入文件覆盖；重复项会按导入规则跳过。地址或端口有误时，先修正对应行再导入。文件较大时可以分批处理，并逐批查看结果。

包含逗号、引号或换行的字段需要正确的 CSV 引号转义。不要把密码或私钥加进表格；非空的敏感凭据列会被拒绝。

## 删除主机

选择条目的删除入口，并确认删除提示。如果其他连接正在引用它作为跳板，先调整这些连接的跳板设置。

删除主机记录不会删除服务器上的文件。配置文件发现的条目需要永久移除时，应编辑原 SSH config；仅在 Pebrel 隐藏时仍可恢复。

换电脑后的凭据处理见[备份与迁移](migration.md)。
