## 打开远端文件列表

先建立[内置 SSH 连接](ssh.md)，点击对应终端窗格，再打开文件面板。目录加载完成后，选择文件夹进入下一级，使用 **上一级**返回。

列表可以跟随终端已知的远端目录。手动浏览其他目录后，点击 **重新跟随**回到终端目录；服务器文件有变化时，点击 **重新读取**刷新。

## 上传文件或文件夹

1. 在远端列表中进入目标目录。
2. 点击 **上传文件**或 **上传文件夹**。
3. 在本机文件选择窗口中选取要上传的内容。
4. 有同名冲突时，选择处理方式。
5. 查看传输进度，完成后确认远端列表中的结果。

服务器上的目标目录需要写入权限。选择本地文件期间如果切换了目标，Pebrel 可能提示“目标已改变”；此时回到正确的远端目录，重新发起上传。

## 下载到本机

选中远端文件或文件夹，点击 **下载到本地**，再选择本机保存位置。下载文件夹时会传输其内容，并显示进度。

完成后，在本机目标目录检查结果。磁盘空间不足、写入权限或网络断开都可能使传输中止，可以在修复原因后重新发起。

## 处理同名项目

| 选项 | 结果 |
| --- | --- |
| **覆盖** | 用传入内容替换目标同名文件 |
| **跳过** | 保留目标已有内容，跳过冲突项 |
| **保留两者** | 另取名称保存，让两份内容同时存在 |
| **取消** | 取消这次操作 |

文件与目录类型冲突时，覆盖可能不可选。重要文件不确定是否应替换时，先使用“保留两者”，再比较两份内容。

## 跳过没有变化的文件

重复传输目录时，可以勾选 **跳过未变**，减少重复复制。Pebrel 根据文件大小和修改时间判断可跳过项，不逐个计算完整内容的校验和。

需要确保重新传输某个同大小、同时间戳的文件时，关闭此选项后再操作。

## 远端复制与粘贴

1. 在源主机的远端列表中选中文件或目录。
2. 点击 **复制远端项目**。
3. 浏览到目标目录；也可以切换到另一条已连接的 SSH 会话。
4. 点击 **粘贴到当前远端目录**。
5. 处理冲突并检查完成状态。

跨主机复制需要源和目标都可连接，并具备读取、写入权限。这里复制的是所选项目，后续粘贴的目标由当前远端目录决定。

## 取消传输

传输过程中点击 **取消**。出现“正在取消”时，等待操作结束再开始下一次传输。取消不会撤回此前已经完成的其他文件；重新传输前检查目标目录，选择合适的同名处理方式。

## 修改远端文本文件

从远端列表打开支持的文本文件，编辑后按 **Ctrl+S / ⌘S**保存回服务器。保存结果与异常处理见[远端文件编辑](remote-edit.md)。
