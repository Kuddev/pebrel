## 准备连接信息

向服务器管理员取得主机地址、端口、用户名，以及密码或私钥。首次连接还需要核对服务器指纹。下面以 `dev@example.com`、端口 `22`为例；操作时换成你的实际信息。

## 添加主机

1. 打开 **设置 → SSH**，选择 **添加 SSH 主机**。
2. 在 **基本**页填写下列信息。
3. 选择认证方式并补充相应字段。
4. 点击 **测试连接**，处理认证提示和服务器身份确认。
5. 测试成功后点击 **保存**。

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| **主机名称** | 开发服务器 | 列表中的显示名称，便于查找 |
| **主机地址** | example.com | 域名或 IP 地址，为必填项 |
| **端口** | 22 | 使用管理员提供的 SSH 端口 |
| **用户名** | dev | 服务器上的账户名 |

地址也可以包含连接信息，例如 `dev@example.com`或 `ssh://dev@example.com:2222`。为便于检查，首次设置时可以分别填写地址、端口和用户名。

## 选择认证方式

**密码**：填写账户密码。需要记住密码时，勾选保存到系统凭据库的选项；否则连接时按提示输入。

**密钥**：点击 **选择私钥文件**，选择私钥，而不是扩展名为 `.pub`的公钥。私钥设置了口令时，连接过程中还会询问口令。

**自动**：先尝试可用密钥，再按需要使用密码。

**交互式**：适合服务器要求多轮提问、动态验证码或其他交互认证的情况。问题会在连接过程中逐项显示。

完整说明见[密码、密钥与交互认证](ssh-auth.md)。

## 确认服务器指纹

首次连接时，Pebrel 可能显示服务器的主机密钥指纹。通过管理员、服务器控制台或其他独立可信渠道核对，确认一致后再接受。

> [!WARNING]
> 已连接过的服务器突然出现指纹变更时，先停止连接并向管理员确认原因。不要仅为了消除提示而直接接受新指纹。

## 打开远端终端

保存后，从 SSH 主机列表选择这个条目的连接入口。登录完成并出现远端提示符后，运行：

```sh
hostname
pwd
```

确认显示的是目标服务器和预期目录。需要并排处理本地与远端工作时，可以使用[分屏](workspace.md)。

## 浏览服务器文件

聚焦这个 SSH 窗格，再打开文件面板。远端文件列表可用于浏览目录、上传、下载和编辑支持的文本文件。完整操作见[SFTP](sftp.md)。

## 连接未成功

超时先检查网络、VPN、地址和端口；“认证失败”先检查账户及认证方式。需要经过代理或跳板机时，编辑主机并打开 **高级**页，按[代理与跳板](ssh-routing.md)设置。

“测试连接”通过后仍无法启动所需程序时，在远端终端检查程序是否已安装、当前账户是否有权限。
