> [!NOTE]
> 本页按 Pebrel 2.1.1 核对，面向带有 **手机远程** 设置的桌面版本（2.0 起提供）和匹配的 Android 客户端。2.1.1 的发行版提供 `Pebrel-v2.1.1-android-universal-preview.apk`，下载见[项目发行版](https://github.com/Kuddev/pebrel/releases)。桌面和手机端的版本需要匹配，旧版本不支持这些流程。

## 准备连接

手机可以查看电脑上运行的任务，并在获准后发送终端输入。**命令仍在电脑上执行**：电脑需要保持运行和网络可达，手机不会在断线后接管电脑的进程。

先准备已安装的 Android 客户端和电脑上的 Pebrel。下面使用 **局域网 / Tailscale** 连接：

- 同一 Wi-Fi 或局域网内，两台设备需要能够互相访问
- 使用 Tailscale 时，两端需要加入可互通的 Tailnet，并选手机可访问的电脑地址
- 网络隔离、系统防火墙或电脑休眠可能阻止连接；不要为配对把本机运行时控制端口直接公开到互联网

当前 Android 项目的最低版本为 Android 8.0（API 26）。这里描述 Android 流程，不代表提供了同样的 iOS 客户端。

## 在电脑上开始配对

1. 打开 **设置 → 手机远程**，点 **开启并配对手机**。
2. 选择 **局域网 / Tailscale**。
3. 在 **网卡** 中选手机可达的地址；**监听端口** 可留空，由程序选择。
4. 保持配对页面打开，准备扫描二维码或复制配对信息。

二维码单次使用，10 分钟后失效。过期或已经用过时，点 **换一个** 生成新的配对信息，不要反复使用旧截图。二维码和完整配对信息都应只交给自己的设备。

## 在 Android 上连接电脑

打开手机的 **连接电脑**，选择一种方式：

| 方式 | 操作 | 适用情况 |
| --- | --- | --- |
| **扫码** | 允许相机，扫描电脑上的二维码 | 手机能看到电脑屏幕 |
| **8 位配对码** | 选择同一局域网发现的电脑，输入二维码下方的 8 位数字 | 本地发现已经找到正确电脑 |
| **粘贴** | 电脑点 **复制完整配对信息**，在手机粘贴，再点 **导入并连接** | 不方便使用相机或局域网发现 |

拒绝相机权限后仍可使用配对码或粘贴。没有发现电脑时，先核对网络与网卡，再尝试扫码或粘贴；不要把 8 位码当作可以跨任意网络寻找电脑的地址，Tailscale 连接也不保证自动发现。

## 核对校验码并批准

手机显示 **等待电脑批准** 后，在两端核对校验码。只有内容一致、而且确实是自己刚发起的配对，才在电脑点 **批准**；不一致或不认识的请求应点 **拒绝**。

8 位配对码用于发起连接，批准时的校验码用于核对这次配对，它们不是同一个用途的码。不要仅因输入过 8 位码就跳过电脑批准。

## 从只看改为允许输入

首次使用时，**新手机的默认权限** 为 **只看**；如果你曾修改过该默认值，配对后先核对这台手机的实际权限。先在手机查看正确的终端，确认任务和电脑对应。

确实需要远程输入时，在电脑 **已配对的手机** 中，把该手机的权限改为 **允许输入**。发送前核对目标终端、当前目录和正在运行的程序；发到普通 Shell 的文字与发到 AI CLI 的文字可能产生不同结果。

只看权限并不允许手机发送终端输入。需要收回操作权限时，在电脑改回 **只看**，不必重新配对。

## 暂停连接或移除手机

- **暂停**：停止监听并断开手机，但保留已经建立的配对
- **移除**：撤销这台手机的授权，下次连接需要重新配对

丢失手机或不再使用该设备时，应在电脑移除它。只退出手机页面不等于撤销电脑上的配对授权。

## 连不上时按顺序检查

1. 电脑是否正在运行、未休眠，**手机远程** 是否开启而非暂停。
2. 所选网卡地址是否能从手机访问，网络是否隔离设备。
3. 二维码是否超过 10 分钟或已经用过；需要时生成新的配对信息。
4. 电脑是否仍有待批准请求；核对校验码后处理。
5. 只有输入不可用时，检查这台手机是否仍是 **只看**。
6. 切换 Wi-Fi 或 Tailscale 地址后，核对实际连接地址；必要时使用新的配对信息。

桌面和手机版本差异较大时，先使用匹配版本再排查。与 SSH 服务器建立终端连接是另一种工作流，见[SSH 连接](ssh.md)。
