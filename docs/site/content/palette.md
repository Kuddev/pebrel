## 按名称查找操作

按 **Ctrl+Shift+P**（macOS 为 **⌘⇧P**）打开命令面板。在搜索框输入想做的操作，例如“设置”“分屏”或“布局”。

使用方向键选择结果，按 **Enter**执行；按 **Esc**关闭面板。暂时不记得快捷键时，可以先从这里查找。

## 打开设置或创建布局

例如，要保存当前窗口布局：

1. 打开命令面板，输入“布局”。
2. 选择 **保存当前窗口布局…**。
3. 在布局配方中输入名称并保存。

下次使用时，在命令面板选择 **打开布局配方…**，再恢复已保存的布局。完整流程见[布局配方](layouts.md)。

## 选择合适的查找入口

| 需要找到的内容 | 使用的入口 |
| --- | --- |
| 打开设置、切换面板等应用动作 | 命令面板：Ctrl+Shift+P / ⌘⇧P |
| PowerShell、WSL 等启动入口 | Shell 选择器：Ctrl+K / ⌘K |
| 已开的标签、常用目录、SSH 主机和 AI 历史 | 快速跳转：Ctrl+Shift+O / ⌘⇧O |
| 自己保存的命令文字 | 顶栏的闪电图标 |

命令面板用于执行应用动作。要运行 `git status` 等 Shell 命令，回到终端输入，或从[保存命令](commands.md)插入。

## 找不到某个动作

先尝试更短的关键字，并确认当前打开的是命令面板。部分动作需要先聚焦一个终端标签；文档标签、没有分屏的标签和不同系统可用的动作可能不同。全局快速终端和托盘设置目前仅在 Windows 提供。
