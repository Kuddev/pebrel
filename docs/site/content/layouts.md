## 保存一套常用排布

布局配方适合保存“两个项目标签，每个标签各有两个窗格”这类重复使用的工作环境。

1. 打开需要的终端，调整标签名称、目录和分屏大小。
2. 打开[命令面板](palette.md)，搜索“布局”。
3. 选择 **保存当前窗口布局…**。
4. 输入 **布局名称**，例如“前后端开发”。
5. 确认保存范围，点击 **保存布局**。

列表会显示保存后的配方，并标出包含多少个标签和分屏。

## 选择保存范围

**当前标签**只保存当前终端标签的排布，适合一组相关窗格。**当前窗口**保存窗口中的终端布局，适合整个项目环境。当前项不是终端时，“当前标签”范围可能不可选。

终端标签的右键菜单也提供 **导出为工作区…**入口。日常重复使用的布局，可以从这里进入相应的工作区保存流程。

## 恢复布局

1. 打开命令面板，选择 **打开布局配方…**。
2. 找到保存的布局，点击 **恢复**。
3. 在新窗口中检查每个终端的目录和连接状态。
4. 启动项目服务或其他需要的程序。

恢复会建立新的终端会话。布局记住的是排布和启动信息，不会复制原来正在运行的进程；例如开发服务器需要在新会话中重新启动。

## 更新已有工作安排

调整当前窗口后，重新保存为一个容易区分的名称，例如“前后端开发 · 数据库”。确认新配方可以正常恢复后，再删除不用的旧配方。

不同电脑上的目录、Shell 和 SSH 凭据可能不同。迁移布局后，先校正这些启动条件，再批量恢复。

## 删除布局配方

在配方列表选择 **删除**，并在确认框中确认。删除配方不会关闭已经打开的终端，也不会删除项目文件。

需要自动恢复最近一次退出前的排布，而不是手动选配方时，开启[启动时恢复上次标签](sessions.md)。
