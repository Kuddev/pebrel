## 先做一份本地加密备份

1. 准备一个已有文件夹，例如 U 盘、已挂载的 NAS 或自己的备份目录。
2. 打开 **设置 → 备份**，在 **备份与恢复** 页面选择 **本地 / 网络目录**，点 **下一步**。
3. 在 **目录** 中填写路径，或用 **浏览…** 选择文件夹，点 **检查连接并继续**。
4. 设置至少 8 位的 **备份密码**，在 **再输入一次** 中确认，点 **下一步**。
5. 勾选需要的内容，点 **完成并开始备份**。只想先保存配置时，选 **完成，稍后备份**。
6. 等待完成提示，并确认页面出现备份记录；以后使用 **立即备份 → 开始备份** 再生成快照。

连接检查只列出已有备份，不写入文件。因此“连接正常”不等于已经成功写入备份，仍需完成第 6 步。

**备份密码与存储服务的登录密码是两回事。** Pebrel 只在本次运行的内存中保留备份密码，下次启动后需要重新输入。恢复时必须使用创建那份备份时的密码；忘记密码就无法解开已有备份，请单独妥善保管。

## 选择要带走的内容

默认推荐外观、终端设置、助手设置、SSH 主机和工作区会话。还可以按需选择同步设置、自定义字体、目录历史和命令历史；每次备份前都能调整，至少选择一项。

- **工作区会话**是窗口、标签和分屏布局，不是正在运行的进程或 AI CLI 对话正文
- **SSH 主机**包含连接配置，不包含 SSH 私钥，也不会复制系统凭据管理器中的密码或 API Key
- **目录历史**可能包含项目路径；**命令历史**可能包含曾经粘贴的令牌，分享或上传前应检查是否真的需要
- **自定义字体**会增加备份大小；外部项目文件和各 AI CLI 自己的数据仍需另外备份

加密并不等于脱敏。自己写进配置或命令中的秘密仍需检查，不要把备份文件和它的密码一起公开。

## 导出文件，迁移到另一台电脑

在备份页的 **文件** 区域选择 **导出备份文件**，选择内容和保存位置，生成 `.pebrel-backup` 文件。首次配置向导也提供导出入口，因此只做一次离线备份不必配置云存储。

把文件安全地复制到新电脑，并准备创建该文件时使用的备份密码。

如果新电脑还停在首次配置向导，先按上面的步骤配置一个已有本地文件夹，选择 **完成，稍后备份**。当前界面的导入入口位于配置完成后的页面，不需要为导入额外开通远程存储。

## 只恢复需要的部分

1. 从已有快照选择恢复，或在 **文件 → 导入备份文件 → 选择文件…** 中打开 `.pebrel-backup`。
2. 按提示输入该备份的密码并点 **解开**；如果本次运行已有可用密码，可能直接显示内容。
3. 检查内容清单，只勾选需要恢复的项目，再确认恢复。
4. 检查外观、主机和配置，新建终端验证 Shell 与路径；跨系统迁移还需修正旧电脑的路径。

**恢复会覆盖本机对应的设置，未勾选的内容不变。** 开始前 Pebrel 会把当前相关文件加密保存为恢复点；恢复完成后可在当前设置页面使用 **撤回**。需要撤回时应先执行并确认结果，不要假设关闭设置页或重启后仍保留同一个撤回入口。

SSH 私钥、系统凭据、Shell 和 CLI 安装不会由布局备份恢复，需要在新电脑另外准备。完整迁移检查见[备份与迁移](migration.md)。

## 使用远程存储

存储向导还支持 WebDAV、S3 兼容存储与 SFTP。准备自己的服务地址和权限，按页面要求填写，再检查连接：

- **WebDAV**：使用已有目录的完整 HTTPS 地址；服务要求应用专用密码时，不要填普通登录密码
- **S3**：填写服务提供的端点、存储桶、区域和访问凭据
- **SFTP**：选择已经保存的 SSH 主机和已有远程目录，沿用该主机的认证配置
- **本地 / 网络目录**：使用已经挂载的目录；选择同步盘时，文件的后续云同步由该同步客户端处理

在这个源码版本中，WebDAV / S3 的凭据管理器保存仅在 Windows 实现。macOS / Linux 需要在启动 Pebrel 的环境中提供 `PEBREL_BACKUP_WEBDAV_PASSWORD` 或 `PEBREL_BACKUP_S3_SECRET`，并将界面的存储密码输入留空。不要把实际秘密写进公开脚本或截图；不方便配置启动环境时，先使用本地文件夹或离线导出。

存储位置按最近 10 份快照保留，成功上传后会尝试清理更旧的快照；清理失败会显示提示，不等于这次上传失败。需要长期保存的一份应另外导出保管。更改存储位置后，页面只列出新位置中的备份，旧位置的备份不会随切换而删除。

## 常见问题

| 现象 | 下一步 |
| --- | --- |
| 解不开备份 | 确认使用的是这份备份的加密密码，而不是网盘或 SSH 密码 |
| 检查连接通过但备份失败 | 核对目录写权限、空间及实际错误；只读连接检查不能证明上传成功 |
| 找不到导入按钮 | 首次向导先完成本地目录配置，再到文件区域导入 |
| 新电脑的 SSH 仍无法登录 | 重新配置私钥和系统凭据，检查用户名和服务器授权 |
| 恢复后程序或项目路径失效 | 修正跨电脑、跨系统路径，再新建终端验证 |
