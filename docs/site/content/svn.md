## 打开工作副本

先用 SVN 客户端检出项目，再在 Pebrel 终端进入这个工作副本。打开 **版本控制面板**，保持 **设置 → 交互 → 侧栏版本控制**为 **自动检测**或 **仅 SVN**。

常规 SVN 操作需要可用的 `svn`命令或对应客户端。安装后，重新打开 Pebrel，并在终端运行 `svn --version`检查命令行环境。

## 添加并提交文件

查看变更列表，把尚未纳入版本控制的新文件添加到 SVN。检查准备提交的文件，填写提交信息后执行提交。

SVN 的添加是将新文件纳入版本控制；它不等同于 Git 的暂存区。提交会联系版本库服务器，需要网络和对应账户权限。

## 更新工作副本

使用更新入口获取服务器上的新修订。更新前检查本地未提交的改动；出现冲突时先处理冲突文件，再继续提交。

对已经手动解决的冲突，**解决**操作会保留当前文件内容并标记冲突已解决。点击前先确认文件里已经没有需要处理的冲突内容。

## Windows 上使用 TortoiseSVN

安装 TortoiseSVN 后，Pebrel 的 **更多 SVN 操作**菜单可以打开它的图形界面。例如：

| 菜单项 | 用途 |
| --- | --- |
| **版本库浏览器** | 查看服务器上的目录和文件 |
| **更新至版本…** | 将工作副本更新到指定修订 |
| **分支 / 标记…** | 创建分支或标记 |
| **切换…** | 切换当前工作副本对应的路径 |
| **合并…** | 打开 SVN 合并流程 |
| **导出…** | 导出不含工作副本管理信息的文件 |
| **修订图** | 查看修订关系 |
| **重定位…** | 更改版本库位置 |
| **属性 / 清理** | 查看属性或处理工作副本维护操作 |

这些操作会进入外部客户端的对话框，按对话框中的路径、修订和确认步骤完成。安装 TortoiseSVN 后若仍提示不可用，重新启动 Pebrel 再检测。

## 对单个文件操作

文件行的更多菜单提供 **显示日志**、**责任追溯**、**获得锁定…**、**释放锁定**、**加入忽略列表…**、**重命名…**、**删除**、**编辑冲突**和 **属性**。

锁定适合需要独占编辑的文件；修改完成后按团队流程提交并释放锁。删除和重命名会改变工作副本状态，提交前再次检查变更列表。

macOS 和 Linux 不提供 TortoiseSVN 的 Windows 图形入口，可以在终端使用 `svn`或系统上的 SVN 客户端完成对应操作。
