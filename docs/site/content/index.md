## 先认识 Pebrel

Pebrel 是桌面终端应用。它把本地 Shell、SSH 会话、文件浏览和 AI 命令行工具放在同一个原生窗口中。你仍然使用自己熟悉的命令、开发工具与账户。

<figure><img src="@ROOT@assets/screenshots/nebula-top-tabs.png" alt="Pebrel 中的顶部标签页与终端工作区" width="1040" loading="lazy"><figcaption>Pebrel 的终端工作区。图片来自项目已公开的应用截图，外观可能与当前平台或主题不同。点击可放大。</figcaption></figure>

**标签页**用于分开不同工作，**窗格**用于并排查看，**SSH 主机**用于连接远程环境。AI CLI 是你自行安装的命令行工具，不是文档网站提供的在线聊天服务。

## 按你现在要做的事开始

第一次使用，请先阅读[快速开始](quickstart.md)。需要挑选系统或处理首次启动，请看[安装与平台支持](installation.md)。

> [!NOTE]
> 本指南对应 Pebrel **1.9.1** 的上游代码。Linux 与 macOS 仍标为 Preview，部分桌面集成仅在 Windows 提供。请以各页的平台提示为准，而不是假设所有按钮在每个系统都存在。

## 如何使用这份指南

按左侧目录阅读，或按 <kbd>Ctrl</kbd> / <kbd>⌘</kbd> + <kbd>K</kbd> 搜索。搜索在你的浏览器内完成，不会把查询发送给远程搜索服务。

每篇指南右侧列出当前页目录。代码示例可以复制；正文可以复制或保存为 Markdown。点击截图可放大；右上角可切换深浅主题。手机上使用右上角菜单打开章节目录。

页面底部的“内容核对来源”提供对应代码的位置。通常无需阅读这些技术资料，也能完成正文中的操作。
