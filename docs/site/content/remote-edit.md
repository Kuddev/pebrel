## 打开远端文本文件

建立内置 SSH 连接，进入[SFTP 文件列表](sftp.md)，打开要修改的文本文件。编辑器标题包含文件名和目标主机，先确认两者再编辑。

远端 Markdown 以源码打开，避免把服务器上的相对资源路径当作本机文件加载。

## 保存回服务器

1. 修改所需内容。
2. 点击 **保存**，或按 **Ctrl+S / ⌘S**。
3. 等待“正在保存”结束，查看保存状态。
4. 必要时在远端终端中读取文件，确认服务器上的结果。

保存目标是打开文件时的原主机和路径。切换到其他 SSH 窗格，不会将这个文件改存到另一台服务器。

## 连接断开或权限不足

网络断开时，先恢复 SSH 连接；权限不足时，检查当前账户是否可以写入该文件及所在目录。编辑器不会自动提权为管理员账户。

错误提示出现后，保留当前编辑内容，再处理问题并保存。重要修改可以先复制到本地文件，防止关闭应用后丢失。

## 文件已经被其他人修改

保存前检查到服务器文件发生变化时，Pebrel 会报告冲突。此时：

1. 复制当前尚未保存的内容。
2. 重新读取远端文件，查看最新版本。
3. 合并双方需要保留的修改。
4. 再次保存并检查结果。

如果文件由部署程序或其他编辑器自动生成，应先暂停相关修改流程，避免不断覆盖。

## 取消读取或保存

远端操作进行时，工具栏提供取消入口。点击后等取消状态结束，再开始下一次操作。取消后可以重新读取远端文件，确认服务器上实际保留的版本。

## 只读文件

超过 **8 MB**的文件可能只预览开头，无法在此保存；非完整 UTF-8 文本也可能只读。此时可以下载后用合适的编辑器处理，或在远端终端使用服务器上的工具。

关闭仍有未保存内容的标签时，按提示选择保存、放弃或取消。文件尚未成功保存前，不要只根据终端连接恢复就关闭编辑器。
