## 切换到源码并保存

1. 从文件树打开本地 Markdown 文件。
2. 点击工具栏的 **文档操作**（省略号），选择 **源码**；也可以按 `Ctrl+/`（macOS 为 `⌘/`）切换。
3. 修改文本。文件名附近的未保存标记会反映编辑状态。
4. 按 **Ctrl+S / ⌘S**，或点击 **保存**。
5. 再次切换源码选项，查看排版后的结果。

Pebrel 1.9.1 的阅读视图用于阅读和选择文字；修改段落、列表与表格时，请在源码中操作。切回阅读视图可以预览尚未保存的编辑，但仍需执行保存才能写入文件。

## 标题、强调和链接

下面这段可以作为一个简单说明文档：

```markdown
# 项目说明

## 开始使用

请先阅读 **安装步骤**，再运行开发服务。

需要特别注意的地方可以写成 *斜体*。

运行 `npm run dev` 后，打开终端显示的地址。

[返回首页](README.md)
```

`#`后面保留一个空格。使用 `##`和 `###`划分子章节，右侧目录会根据这些标题更新。

## 列表和任务清单

```markdown
1. 安装依赖。
2. 启动服务。
3. 打开浏览器。

- 开发环境
- 测试环境

- [x] 准备配置
- [ ] 运行测试
```

完成任务时，在源码中将 `[ ]`改为 `[x]`，保存后查看阅读效果。阅读视图中的任务框用于展示完成状态，不作为修改文件的复选框。

## 代码块

用三条反引号包围代码，在第一行反引号后注明语言。下面的围栏内层是一段完整的 Markdown 示例：

````markdown
```sh
echo Hello, Pebrel
```
````

阅读时会显示代码排版，并提供复制按钮。常见语言可写 `sh`、`powershell`、`python`、`rust`、`json`或 `lua`。

## 表格

```markdown
| 环境 | 地址 | 状态 |
| --- | --- | --- |
| 开发 | localhost | 运行中 |
| 测试 | test.example.com | 待检查 |
```

每行用 `|`分隔单元格，第二行定义表头分隔线。新增一行时，在源码中按相同列数补一行；需要在单元格显示竖线时，写成 `\|`。

## 图片

```markdown
![终端工作区截图](images/workspace.png)
```

括号内是相对当前 Markdown 文件的图片路径。分享文档时，把被引用的图片目录一起保留。图片无法显示时，检查路径大小写和文件是否存在。

## 数学公式

行内公式用 `$...$`，独立公式用 `$$`围起：

```markdown
直角三角形满足 $a^2+b^2=c^2$。

$$
\frac{1}{2}+\frac{1}{3}=\frac{5}{6}
$$
```

切回阅读视图检查排版。复杂 LaTeX 的支持范围以实际渲染为准；不正常的表达式可先缩小成一个简单公式，再逐步添加内容。

## 撤销和处理保存冲突

在源码编辑状态下，**Ctrl+Z / ⌘Z**撤销，**Ctrl+Shift+Z / ⌘⇧Z**重做。保存使用 **Ctrl+S / ⌘S**。

如果其他程序已经修改了文件，保存可能提示冲突。先复制当前编辑内容，再重新读取磁盘版本，比较后合并需要保留的部分。不要直接重读并丢掉尚未保存的文字。
