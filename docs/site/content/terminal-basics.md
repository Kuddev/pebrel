## 输入命令并查看结果

终端提示符后的光标表示 Shell 正在等待输入。输入命令，按 **Enter** 执行；程序结束后，提示符会再次出现。

```sh
echo Hello, Pebrel
```

如果程序持续显示日志且没有新的提示符，它可能还在运行。可以另开一个[标签页或分屏](workspace.md)执行其他命令。

## 查看和切换目录

| 操作 | PowerShell / macOS / Linux / WSL | Windows cmd |
| --- | --- | --- |
| 查看当前目录 | `pwd` | `cd` |
| 列出文件 | `ls` | `dir` |
| 返回上一级 | `cd ..` | `cd ..` |
| 进入指定目录 | `cd "路径"` | `cd /d "路径"` |

命令在当前窗格的目录里运行。切换到另一个窗格后，先查看它的目录；各个 Shell 的目录可以不同。

路径中的空格需要用引号包围。例如 PowerShell 中的 `cd "C:\My Projects\demo"`，或 macOS 中的 `cd "$HOME/My Projects/demo"`。

## 停止运行中的命令

通常按 **Ctrl+C** 可向当前程序发送中断请求。Windows / Linux 有文字选中时，Ctrl+C 会先复制选区；先清除选区再中断。macOS 复制使用 **⌘C**，中断仍使用 **Ctrl+C**。

程序可能要求确认退出，或自行处理这次中断。回到提示符后，再输入下一条命令。

## 查看之前的输出

使用滚轮或触控板向上滚动。普通终端画面还支持：

| 按键 | 作用 |
| --- | --- |
| Shift+PageUp / Shift+PageDown | 按页查看输出 |
| Shift+Home | 移到保留的历史顶部 |
| Shift+End | 返回输出底部 |

进入 Vim、less 等全屏程序后，优先使用该程序自己的导航按键。程序接管鼠标时，按住 **Shift** 再用鼠标，可使用终端的选择或滚动操作。

## 保留更多历史输出

打开 **设置 → 外观 → 终端外观**，调整 **回滚行数**。这个数值控制每个窗格能保留的历史行数；修改后，新建终端窗格使用新设置。增加行数会增加长时间运行时的内存用量。

**滚动速度**用于调整鼠标滚轮滚动的行数，修改后立即生效；触控板手势不受该倍率控制。

## 当前窗格运行在哪台机器

本地 Shell 使用电脑上的文件和程序；WSL 使用所选发行版的环境；SSH 使用远端服务器的环境。需要确认位置时，先查看标签、Shell 类型和当前目录，再运行 `pwd` 或 `hostname`。

这一步在复制文件路径、启动 AI 工具和执行修改命令前尤其有用。进一步阅读：[WSL](wsl.md)、[SSH](ssh.md)、[复制与粘贴](clipboard.md)。
