## 设置全局热键

**快速终端目前仅在 Windows 提供。** 设置完成后，可以在其他应用中按组合键唤起 Pebrel。

1. 打开 **设置 → 按键映射**。
2. 找到 **快速终端**，录入准备使用的组合键。
3. 在 **快速终端打开方式**中选择需要的模式。
4. 切换到其他应用，按一次热键检查唤起效果，再按一次检查隐藏行为。

如果提示热键注册失败，换一个没有被系统或其他应用占用的组合。只在 Pebrel 窗口内生效的普通快捷键，不能代替这个全局热键。

## 选择打开方式

| 模式 | 适合的使用方式 |
| --- | --- |
| **独立窗口** | 随时输入几条短命令，不打断主工作区 |
| **唤起已有窗口** | 回到已经打开的项目和终端 |

“唤起已有窗口”会召回已有工作区，不会每次都额外创建一个标签页。选择独立窗口后，可以按需要调整它的窗口大小。

## 从托盘重新打开窗口

打开 **设置 → 高级 → 会话生命周期**，开启 **常驻系统托盘图标**。之后可以从系统托盘中的 Pebrel 入口重新显示窗口。

希望关闭窗口后仍保留运行中的任务，请同时开启 **关窗后保留后台会话**。隐藏窗口后，任务会继续输出；从托盘或热键唤回时，可以接着查看。

## 完全退出

需要结束 Pebrel 时，使用退出应用的操作，而不是仅关闭一个设置为后台保留的窗口。保存文档并结束需要处理的任务后再退出；应用进程结束后，全局热键也不再驻留。

macOS 和 Linux 可以通过系统应用切换、新建窗口和普通快捷键操作 Pebrel。会话恢复设置见[会话保存与恢复](sessions.md)。
