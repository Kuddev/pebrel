## 选择终端输出

拖动鼠标选择一段文字；双击可选择一个词，三击可选择一行。按住 **Shift** 可以扩展已有选区。

Vim 等程序可能接管鼠标。需要复制它显示的文字时，按住 **Shift** 再拖动，使用终端自身的选区。

## 复制和粘贴文字

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 复制选区 | Ctrl+Shift+C | ⌘C |
| 粘贴剪贴板 | Ctrl+V 或 Ctrl+Shift+V | ⌘V |

Windows / Linux 中，Ctrl+C 在存在选区时也会复制文字；没有选区时，它用于中断正在运行的程序。

粘贴前点击目标窗格。准备把命令发到服务器时，先确认焦点确实在对应 SSH 终端。

## 选中即复制和右键粘贴

打开 **设置 → 交互 → 鼠标与选区**，开启 **选中即复制**。之后鼠标选择结束时会复制选区，右键可以粘贴。需要使用常规右键菜单时，将这项设置关闭。

这个选项适合频繁从日志中复制文字；如果经常需要右键选择其他动作，保留默认交互会更方便。

## 粘贴多行命令

在 **设置 → 交互**开启 **粘贴前确认**。在普通 Shell 中粘贴多行或高风险内容时，检查确认框里的文本，再决定是否继续。

确认时留意三个位置：当前主机、当前目录，以及命令是否包含删除、提权或覆盖操作。多行文本送入 Shell 后，换行可能触发执行。

全屏程序和使用 bracketed paste 的程序会按各自的粘贴方式处理输入；不要把确认框当成所有应用都必定显示的步骤。

## 粘贴图片

复制一张图片后，在目标终端执行粘贴。Pebrel 会将图片保存为 PNG，再插入对应文件路径。检查输入区中的路径，按正在使用的工具要求提交。

在 WSL 或 SSH 中，路径需要指向该环境可访问的图片。SSH 传图依赖远端连接和传输成功；失败时先处理提示，再重试。图片是否显示为附件缩略图由接收的 CLI 决定。

关于图片预览、终端内嵌图像及清理缓存，见[图片](images.md)。

## 将输出交给 AI

选择报错或日志，右键打开 **发送到聊天**，再选择目标 AI 窗格。这样可以直接携带选中的输出继续提问。具体示例见[发送到聊天](send-to-chat.md)。
