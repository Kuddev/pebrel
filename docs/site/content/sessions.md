## 下次打开时恢复标签和目录

打开 **设置 → 高级 → 会话生命周期**，开启 **启动时恢复上次标签**。正常退出后再次启动 Pebrel，会按已保存的信息重新建立终端标签、分屏和已知目录。

建议先用两个空闲终端测试：分别进入不同目录，正常退出并重开，再运行 `pwd` 检查恢复位置。SSH 标签需要重新连接服务器，缺少认证信息时会再次询问。

恢复标签会启动新会话。上次终端里没有保存的屏幕内容和普通程序的内存状态，不会作为整个进程一起恢复。

## 关窗后让任务继续运行

**此功能仅在 Windows 提供。**

1. 在 **设置 → 高级 → 会话生命周期**开启 **关窗后保留后台会话**。
2. 建议同时开启 **常驻系统托盘图标**，方便重新打开窗口。
3. 运行一个需要持续进行的任务，再关闭窗口。
4. 通过托盘或快速终端重新唤起 Pebrel，查看原任务的输出。

这项设置使应用在关窗后继续驻留。真正退出应用、结束进程、注销或重启电脑会终止本地进程；需要跨重启运行的任务，应使用相应系统服务或任务管理工具。

## 接续 AI 对话

希望恢复标签时继续之前的 Claude Code 或 Codex 对话，在开启标签恢复后，再开启 **恢复时接续 AI 对话**。

恢复需要可用的会话标识、原会话记录和对应 CLI。Pebrel 会尝试用 CLI 的恢复入口接续对话；工具仍可能要求登录或确认工作目录。

恢复失败时，右键相关终端标签，使用可用的 **重试会话恢复**或 **选择要继续的对话…**。也可以从[AI 会话历史](ai-history.md)手动选择。

## 应该开启哪一项

| 你的需要 | 设置 |
| --- | --- |
| 重启应用后重新打开标签、分屏与目录 | 启动时恢复上次标签 |
| Windows 关闭窗口但继续运行本地任务 | 关窗后保留后台会话 |
| 重开时接续受支持的 AI 对话 | 启动时恢复上次标签 + 恢复时接续 AI 对话 |
| 按项目保存几套可重复打开的布局 | 使用[布局配方](layouts.md) |

## 远端任务需要长时间运行

SSH 连接断开时，远端命令是否继续由服务器上的程序和会话管理方式决定。对必须持续运行的远端任务，建议使用服务器上已安装的会话保持工具或系统服务；重新连接后按对应工具的恢复方式继续。

关闭 Pebrel 前，仍应保存打开的文档。文档编辑缓冲区的保存提示与终端会话恢复是两套操作。
