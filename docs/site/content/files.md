## 打开项目文件

先在终端进入项目目录，再按 **Ctrl+Shift+F**（macOS 为 **⌘⇧F**）打开文件树。展开文件夹，选择要查看的文件。

文本文件可以在编辑器中打开，Markdown 默认以排版后的阅读视图打开。聚焦内置 SSH 会话时，文件面板显示对应的[SFTP 远端文件](sftp.md)。

## 跟随终端目录

在终端执行 `cd`切换目录后，文件树可使用终端上报的目录。手动浏览过其他位置时，点击 **跟随当前终端并刷新**，或使用按钮提示的 **Alt+R**，回到当前终端目录。

读取失败时先看面板里的路径和错误提示。旧目录可能仍显示在面板中，修复路径或权限后再刷新。

## 按名称找文件

在文件树搜索框输入文件或文件夹名称。按需要切换以下选项：

| 选项 | 使用场景 |
| --- | --- |
| **区分大小写** | 区分 `README`与 `readme` |
| **全词匹配** | 按完整词匹配，而不是任意部分字符 |
| **使用正则表达式** | 用模式匹配文件名，例如 `\.md$` |

搜索用于查找名称。要查找文件里面的文字，可以在终端使用已安装的搜索工具，例如：

```sh
rg "TODO" .
```

出现扫描限制或目录权限提示时，先缩小到相关项目目录，再搜索。

## 从文件夹新建终端

右键目标文件夹，选择 **在此处打开终端**，或使用面板的 **在此新建终端**入口。新终端打开后运行 `pwd`检查位置；cmd 使用 `cd`。

WSL 目录会使用适合该环境的路径。需要把文件路径交给 Linux 命令时，使用菜单中的 **复制 Linux 路径**。

## 复制路径或使用系统应用

文件或目录菜单提供 **复制路径**、**打开**以及在系统文件管理器中显示的入口。要把路径放进命令时，粘贴后检查路径中是否有空格，并按 Shell 需要添加引号。

文件不适合用内置编辑器处理时，可以在系统文件管理器中打开，或使用文件信息中的 **用默认应用打开**。

## 从项目中忽略或删除文件

在 Git 项目里，**加入 .gitignore**可为不需要跟踪的文件添加忽略规则。已经被 Git 跟踪的文件，仍需按 Git 的规则处理；忽略规则不会从历史提交中移除内容。

选择 **删除**后，阅读 **移入回收站**确认框，核对文件名和路径。批量处理前先确认没有选错项目目录；操作失败时按系统提示检查权限或回收站支持情况。

查看改动和提交文件，见[版本控制](vcs.md)。
