## 调整鼠标操作

打开 **设置 → 交互 → 鼠标与选区**。

**选中即复制**开启后，松开鼠标时自动复制，右键直接粘贴。经常使用右键“发送到聊天”时，可以关闭它，保留常规菜单。

**焦点跟随鼠标**开启后，鼠标移到窗格会改变输入焦点。希望明确点击后才切换输入目标时，将它关闭。多个 SSH 窗格并排时，输入前注意焦点位置。

**粘贴前确认**用于在普通 Shell 粘贴多行或高风险文本前显示确认。具体规则和快捷键见[剪贴板](clipboard.md)。

## 调整侧栏宽度

开启 **拖拽调节侧栏宽度**，再拖动侧栏与工作区之间的分隔线。需要固定宽度、防止误拖时，将此项关闭。

分隔线无法拖动时，先检查这个开关。终端内的分屏分隔线与侧栏宽度分别调整。

## 更改标签页布局

在 **标签与窗口**分组中：

| 设置 | 可选方式 |
| --- | --- |
| **标签栏位置** | 左侧边栏 / 顶部 |
| **标签展开动效** | 滑动 / 立即 |
| **新标签位置** | 当前标签之后 / 列表末尾 |

需要减少移动效果时，把标签展开动效改为“立即”。新标签位置影响之后新建的标签，不会把已有标签全部重新排序。

显示关闭按钮的设置在 **外观**页；关闭显示后仍可使用菜单、中键或快捷键关闭标签。

## 再次启动 Pebrel 时打开哪里

**新建实例行为**可选择创建新窗口、附加到最近使用的窗口，或附加到此桌面最近使用的窗口。

经常从项目目录启动 Pebrel 时，选择附加到已有窗口可以集中管理标签；需要每个项目独立窗口时，选择创建新窗口。

关窗后的后台运行、登录自启动和标签恢复在 **设置 → 高级**中配置，见[会话保存与恢复](sessions.md)。

## 版本控制与中文粗体

**侧栏版本控制**可设为自动检测、仅 Git 或仅 SVN。切换后进入相应项目目录并打开版本控制面板。

**中日韩粗体提亮**控制中文等相关字符的粗体呈现方式。需要调整字体本身时，转到 **外观 → 终端外观**。

## 恢复默认设置

设置页底部选择 **恢复默认设置**，阅读确认范围后继续。此操作恢复设置和快捷键、备份原设置，并保留 SSH 主机、凭据和历史。

只需要改回一个选项时，优先调整该项，避免重置其余个性化设置。
