## 打开命令补全

在 **设置 → 终端**开启 **启用命令补全**。回到终端，在普通 Shell 提示符处输入命令或路径的开头，查看出现的建议。

补全会结合可用的历史记录和路径信息。第一次进入新环境、尚无相关历史时，建议可能较少。

## 选择建议的显示方式

在同一设置页中找到 **补全样式**：

| 选项 | 显示方式 |
| --- | --- |
| **行内灰字** | 建议接在已输入内容后面，适合直接续写命令 |
| **弹窗列表** | 在输入附近列出候选项，适合查看不同选择 |

两种样式使用同一补全功能。可以先试行内灰字；需要更明显的候选提示时，再切换列表样式。

## 接受一条建议

**补全接受键**可以设置为 **Tab**、**右方向键**或**Tab 或右方向键**。建议出现后，使用所选按键接入建议内容，再检查整条命令，按 Enter 执行。

如果你希望保留 Shell 自己的 Tab 补全，可以让 Pebrel 使用右方向键。更改后回到 Shell 提示符处试用，不必关闭整个窗口。

## 在不同环境使用

本地 Shell、WSL 与 SSH 会话各自使用对应环境的上下文。例如，WSL 项目中的 Linux 路径应在 WSL 窗格里输入，不要拿 Windows 路径来判断补全是否正确。

Vim、全屏程序或正在运行的 AI CLI 有自己的按键操作。需要检查 Pebrel 补全时，先退出到普通 Shell 提示符。

## 没有出现预期建议

先检查 **启用命令补全**是否打开，再确认当前输入位置是 Shell 提示符。输入一次完整命令、执行完成后，再输入相同前缀测试历史建议。

路径建议不符合当前目录时，运行 `pwd`（cmd 使用 `cd`）确认目录是否正确。出现两套重复建议时，可以关闭 Pebrel 补全或 Shell 插件中的一套。经常重复使用且不适合依赖历史的长命令，可以存入[保存命令](commands.md)。
