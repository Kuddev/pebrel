## 预览图片文件

从文件树选择图片，可以查看支持格式的预览。常见格式包括 PNG、JPEG、WebP、GIF 和 BMP；超出大小限制或解码失败时，可使用系统默认应用打开。

PDF 提供首页缩略图，适合辨认文件。需要翻页、批注或编辑时，使用 PDF 阅读器。Linux 的 PDF 缩略图依赖可用的 `pdftoppm`。

## 把剪贴板图片交给命令行工具

1. 复制图片本身，例如截图结果，而不是图片文件名。
2. 点击准备接收图片的终端窗格。
3. 按 **Ctrl+V / ⌘V**粘贴。
4. 等待 PNG 保存或远端上传完成。
5. 检查插入的文件路径，再按工具的要求提交。

Pebrel 会生成图片文件并插入路径。AI CLI 是否把路径显示为附件缩略图，取决于它自己的图片输入功能。

剪贴板同时包含非空文字时，可能优先粘贴文字。看到意外文本时，先撤回或清空输入，再重新复制图片。

## 在 WSL 或 SSH 中粘贴

WSL 使用转换后的 Linux 可访问路径。原生 SSH 会话需要先把图片传到远端，再插入远端路径；传输失败时先修复连接或权限。

同一张本机图片需要发给不同主机时，分别聚焦对应窗格再粘贴。图片不参与[广播输入](broadcast.md)。

## 在终端输出里显示图片

前台程序输出 Pebrel 支持的 **OSC 1337**图像协议时，终端可以内嵌显示图片。仅打印一个 `.png`路径不会自动变成图像。

需要使用这一方式时，选择能够输出相应协议的命令行工具，并按其说明配置。普通图片浏览优先使用文件预览，不必自己编写转义序列。

## Markdown 中的图片

本地 Markdown 可以引用可访问的图片，路径相对文档位置。比如 `![截图](images/example.png)`要求文档旁有 `images/example.png`。

图片缺失时，先在文件树检查目标文件，不要仅修改显示文字。远端 Markdown 编辑不会自动把所有关联图片下载到本地阅读器。

## 清理粘贴产生的文件

图片粘贴后，可以从插入的路径找到副本。不再需要时按该位置删除；远端副本需要在服务器上清理。

发送前检查截图中是否包含密码、Token 或私人信息。删除本机副本不会撤回已经交给远端服务器或 AI 服务的内容。
