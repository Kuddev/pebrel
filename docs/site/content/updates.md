## 检查是否有新版本

打开 **设置 → 应用**，查看当前版本并点击 **检查更新**。发现新版本后，打开更新详情查看下载和安装操作。

**自动检查更新**控制后台检查，预下载选项用于提前下载更新包。当前界面中的更新通道显示为 **Stable**。

更新前保存文档，并结束或安排好运行中的任务。下载完成后仍需按安装提示继续，重新启动后才能使用新程序。

## Windows 安装版

使用官方安装程序安装的版本，可以通过更新详情下载并安装。按提示完成安装器流程，然后重新启动 Pebrel。

完成后回到 **设置 → 应用**，检查版本号是否已更新。安装正在进行时，不要同时手动替换应用文件。

## Windows 便携版

便携目录使用手动替换包的方式：

1. 下载匹配架构的新 ZIP。
2. 备份配置，并正常退出 Pebrel，包括后台驻留实例。
3. 将新 ZIP 完整解压到新的目录。
4. 迁移放在旧程序目录旁的个人配置或素材。
5. 启动新目录中的 `pebrel.exe`，检查版本和设置。

确认新版本正常后，再清理旧程序目录。只替换 EXE 可能遗漏随包资源；ARM64 与 x64 包也不要混用。

## macOS

从 Applications 中运行的可写 Pebrel `.app`可使用受支持的更新安装入口。按更新详情提示保存工作、退出相关运行实例并继续安装。

如果提示当前安装位置不支持更新，或安装未成功：下载匹配 Apple Silicon / Intel 的官方 DMG，退出 Pebrel，再将应用拖入 Applications 替换。

不要从仍挂载的 DMG 或被系统临时转移的路径直接安装更新。完成后从 Applications 重新启动并检查版本；首次启动的系统确认见[安装](installation.md)。

## Linux

使用与当前安装方式一致的新包。DEB 用户通过包管理器安装新版本；AppImage 用户退出旧进程后运行新的 AppImage；TAR.GZ 用户完整解压新包后使用其中的 `AppRun`。

Linux 当前仍需手动完成包替换。更新检查可以帮助发现版本，不会自动代替包管理器更新系统安装。

## 更新失败

**下载失败：**检查网络代理、磁盘空间和 Release 资产是否可访问。

**无法写入应用目录：**检查安装位置与权限，必要时改用官方安装包手动更新。

**重开后还是旧版本：**检查启动的是不是旧目录中的快捷方式，以及后台是否仍有旧进程。

反馈时提供版本号、系统、架构、安装方式和完整错误文字。升级前的数据保存方法见[备份与迁移](migration.md)。
