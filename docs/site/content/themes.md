## 从已有主题创建副本

1. 打开 **设置 → 外观 → 更换主题**。
2. 选择接近目标的主题，从 **作为模板**入口进入 **自定义主题**。
3. 填写 **主题名称**，例如“我的深色配色”。
4. 修改需要的颜色或字体，观察旁边的预览。
5. 点击 **保存并应用**，回到终端检查效果。

创建副本不会改动内置模板。只想先收藏这套配色时，点击 **仅保存**，稍后再从自定义主题中选择。

## 调整常用设置

**常用设置**包含终端背景、文字颜色、强调色、光标颜色、字体、字号、行高和不透明度。

例如，文字拥挤时可以略微增加行高；光标不容易看清时，选择与背景有明显差异的光标颜色。预览包含终端、界面和 ANSI 色彩，修改后分别检查这几处。

预览中的变化在应用前不会改动当前终端。离开编辑器时如出现未保存提示，可以选择继续编辑，或放弃草稿。

## 调整调色板和界面细节

展开 **高级设置**，可继续调整 **ANSI 16 色**、选区背景、选区文字、光标文字，以及主题支持的圆角、留缝、阴影和分割线。

ANSI 颜色影响命令行程序输出的不同颜色；选区颜色影响鼠标选中的文字。修改后查看一段带颜色的输出和一段选区，确认文字仍清晰。

颜色或数值格式不正确时，修正标出的字段再保存。需要回到当前模板的起点时，使用 **重置修改**。

## 导入其他终端的配色

选择 **导入**并打开主题文件。Pebrel 可以读取自身 JSON 主题，以及当前版本支持的其他静态主题格式。

1. 选择文件，等待读取完成。
2. 一个文件包含多套配色时，在候选主题中选择一项。
3. 查看 **导入说明**，确认不支持或未映射的字段。
4. 点击 **作为模板**，将配色载入编辑器。
5. 检查预览后点击 **保存并应用**，或 **仅保存**。

如果某种主题文件不能直接导入，可先整理为 Pebrel 支持的静态配色格式；包含脚本或动态计算的整份配置，也应先转换为纯配色数据。

## 导出主题

在编辑器选择 **导出**，选择目标格式，查看 **此格式不会保留的设置**，再指定保存位置。

保留 Pebrel 的完整主题设置时，使用 **Pebrel**格式。导出到其他终端时，主要保留目标格式能表达的配色，Pebrel 特有的界面设置可能不会保留。

## 避免丢失草稿

切换模板会替换当前尚未保存的修改。想比较两个方案时，先保存第一个副本，再从另一个模板创建新副本。

多个窗口同时编辑主题而出现保存冲突时，先保留当前草稿，再重新读取主题库比较，不要覆盖另一个窗口刚保存的结果。
